Gráf és topológia

Csomópontok, vezetékrétegek és keretek SVG-n: síkban és izometrikus „iso-board” nézetben, áttekintő térképpel, valamint egymásra rakott rétegsíkok pillérekkel és jelzőfényekkel.

Villamos topológia — VRG-2611-03 graph · minimap

Főelosztó → alelosztók → áramkörök → eszközök, „Földszint” és „Emelet” keretben. Egy tabulátor-megálló: ←↑→↓ a nézetet mozgatja, Enter a középhez legközelebbi csomópontra lép, onnan a nyilak térben lépkednek; Szóköz kijelöl, Ctrl+A mindet, F2 átnevezés, Delete a regiszter graph.delete akcióját futtatja, + − 0 nagyít / illeszt, Esc kijelölést töröl. Egér: húzás = mozgatás, görgő = nagyítás, Ctrl+kattintás = hozzáadás, Shift+húzás = keretes kijelölés. Állapotok: kijelölt (AE2, K2 — jég), fókusz (V2 — szaggatott jéggyűrű), rejtett réteg (Védőföld), tervezett (szaggatott Világítás), aktív (meleg futófény).

KIJELÖLÉS // —

Ugyanez iso-board vetületben graph · projection:'iso'

Ugyanaz az adat izometrikus síkon: a csomópontok kiemelt iso-lapok, a főelosztó izzó központ (meleg = a rendszer dolgozik), a vezetékek az iso-tengelyek mentén futnak, lekerekített törésekkel. Minden réteg látszik; a billentyűzet ugyanaz.

Elemkészlet graph — node kinds · edge styles

Buborék (kártya: cím, mono alcímke, port-pontok, MINI jelvény), telt pont = csomópont, üres rombusz = elágazás, kis négyzet = végpont, hatszög panel. Vezetékek: metró (alapstílus), görbe, egyenes; tervezett = szaggatott, aktív = meleg futófény (csökkentett mozgásnál álló), nyílhegy, felirat.

Rétegköteg layerstack

Öt sík egymás fölött; a szaggatott függőleges pillérek ugyanazt az entitást kötik össze a síkok között, a meleg fényoszlopok az aktivitást jelzik. A síklista egy megálló (nyilak; szem = megjelenítés, solo = szóló). A színpadon ↑↓ sík, ←→ entitás, S szóló, H elrejtés, Esc szóló vége. Rámutatás vagy fókusz kiemeli a pillért és az entitás minden síkbeli pontját (jég). Itt az „Átjáró GW-01” ki van emelve.
