# VRG Mobile UI audit: field features (static, read-only)

Scope: `Mobile/android/feature-{pager,tag,watch,map,weather,vault,workflow,sketch}/src/main/kotlin`. Checklist:
`docs/mobile/UI-CHECKLIST.md`. Paths below are relative to `Mobile/android/`. Nothing was edited, built or run.

How the dp budgets were worked out: phone 360 dp wide. Feature screens use a 16 dp side padding (328 dp usable); the
sketch fronts use 12 dp (336 dp). Text width is estimated at about 0.55 em per character (11 sp label ≈ 6 dp per
character at scale 1.0, 9 dp at 1.5). A `VrgChip` is its text plus 20 dp of horizontal padding. In a `Row`, children
without a weight are measured in order, so the last fixed children get whatever width is left, down to 0 dp. Tagged
**sketch-owned**: report only, another session fixes these.

Already known and not reported again: the `faint` and `glowDim` tokens fail contrast when used as text, and many texts
are 10 sp or smaller. Per-file counts are at the end.
