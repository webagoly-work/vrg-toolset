# M68 · Post-it (`postit`): notes pinned to a point of any screen — with the Desktop's WP-50

**Goal.** The Founder, 2026-11-25: a Post-it plugin of the Notes app. *"Once armed, the next click on VRG Desktop and the next
tap on the Mobile screen puts a faint mark on that point of the screen and opens a text box (like how it is in Planner) next to
it … a toggle in the settings, turned on shows two small buttons on the upper left … a show/hide toggle … and the Arming /
Disarming switch … on top of anything … mainly as a meta app feature for tester users … these comments then can be downloaded
/ called in by me so that they can be overlaid on my phone / desktop (in a see-what-they-see sense) when I toggle dev overlay."*
Built 2026-11-25 (cloud session), **BETA** on both sides.

The design, the anchor, the format and the decisions: **[`docs/notes/POSTIT.md`](../../notes/POSTIT.md)** (HU: `POSTIT.hu.md`).

## Decisions (POSTIT-Q01 … Q07, taken as A while building; the Founder may revisit)

See `docs/notes/POSTIT.md` §8. In short: a file is the transport; DEV needs Dev / All level on the PC and a Settings switch on
the phone; the phone layer is in-app (dialog windows sit above it); PC notes anchor to the pane under the click; no screenshots.

## Tests (cloud)

- `node Dashboard/test/run.js WP-50` → `wp-50.test.js` (11): the fixture and every refusal reason; make / bundle keep only the
  known keys; the inbox merge (same file twice = no change, a newer edit wins, authors apart); px ⇄ fraction and the card
  flipping left at the edge; screen keys of the views (a web tab's query is never kept) and the topmost pane under a point;
  the store's random author id; with a fake window: off = no window, on = a transparent sandboxed child window that lets the
  mouse through until armed or hovered, arm → place → save → state → edit → done → export → remove, the DEV layer refused at
  User level, two files called in, devHide, settle, the same files twice = no change; the settings keys refuse bad values.
- The overlay page was rendered in headless Chromium with a stubbed bridge (cards, the armed state, the editor beside the
  mark, the menu) and checked by eye.
- `gradlew :kit-core:test` — `PostItTest` (7): the same fixture, the same hues and the same id from the same draws as the JS
  twin, every refusal reason, the round trip, the merge, the placement and stacking, the screen keys. kit-core 289 green.

## What could not be verified here

- **The Android modules were not compiled** (no Google Maven in the cloud). The first Actions run of this branch is their check
  (`kit/postit/*`, `ShellActivity`, `MobileApp`, `feature-settings`).
- **Electron was not run**: the child window's transparency, `setIgnoreMouseEvents(…, {forward})` and focus hand-over are
  Windows behaviour. `node Dashboard/test/run.js WP-50` on the PC also runs no selftest probe for it yet.

## PC-n ellenőrizni (VRG Asztal)

1. Beállítások → *Post-it jegyzetek a képernyőn* be. Bal felül, a címsor alatt megjelenik 👁 és 📌. Kikapcsolva eltűnnek.
2. Nyiss egy beépített alkalmazást (pl. Készlet) és egy webes lapot. Az egér mindenhol átmegy: görgetés, kattintás, gépelés
   működik a rétegtől függetlenül.
3. 📌 → a felület halvány sárga keretet kap. Kattints az alkalmazás egy pontjára: halvány jel és mellette a szövegdoboz. Írj,
   Ctrl+Enter. A kártya ott lebeg.
4. Mozgasd / méretezd át a panelt, válts Irányítópult ⇄ Asztal nézetet: a kártya a panellel megy, más nézeten eltűnik.
5. A kártyára kattintva szerkeszthető, *Kész* áthúzza, *Törlés* (kétszer) eltávolítja. Esc mégse.
6. 👁 elrejti / mutatja. Az ablak minimalizálása, visszaállítása, teljes képernyő: a réteg követi.
7. Jobb klikk a 📌-on → név → *Exportálás fájlba…*: a fájl elkészül.
8. Szint: Fejlesztő. A menüben *Behívás fájlból…*: válassz egy telefonos és egy PC-s exportot. Megjelenik a DEV gomb (be), a
   PC-s tesztelő jegyzetei a megfelelő panelen, a tesztelő színében. Tesztelőnként ki-be kapcsolható.
9. Szint vissza Felhasználóra: a DEV gomb és a tesztelők jegyzetei eltűnnek.

## Telefonon ellenőrizni

1. Beállítások → *Post-it jegyzetek* → *Post-it jegyzetek a képernyőn* be. Bal felül megjelenik 👁 és 📌 a Kezdőlapon, egy
   funkcióban (pl. Gyorsjegyzet, Vázlat) és a Katalógusban is.
2. A réteg nem zavar: a gombokon kívül minden koppintás, görgetés, lapozás az alkalmazásé.
3. 📌 → halvány sárga keret és felirat. Koppints egy pontra: halvány jel, mellette a szövegdoboz, a billentyűzet nem takarja.
   Mentés. Vissza gomb: mégse. Kívül koppintás: ment.
4. Válts funkciót: a jegyzet csak azon a képernyőn látszik, ahová tetted. Forgasd el a telefont: ugyanazon a relatív helyen.
5. Kártyára koppintva: szerkesztés, *Kész*, *Törlés* (kétszer).
6. Hosszan nyomva a 📌-t: név, *Küldés / exportálás* → megosztó lap; küldd el magadnak (pl. levélben).
7. Fejlesztői telefonon: Beállítások → *Fejlesztői réteg engedélyezése*. Megjelenik a DEV gomb. *Behívás fájlból…* → a
   tesztelő fájlja: a jegyzetei a megfelelő képernyőkön, színnel, névvel. Egy PC-s fájl behívása nem rajzol semmit a telefonon,
   de a menüben listázza.
8. Egy exportot *szövegként* megosztva a VRG Mobile-nak: „Post-it: … új” üzenet, nem Gyorsjegyzet nyílik.
9. Kikapcsolva (Beállítások): semmi nem látszik, a jegyzetek visszakapcsolva megvannak.
