## The contract (kept by the WebView)

- http and https only; `mailto:` / `tel:` go to the phone's apps; `intent:`, `javascript:`, `file:` and every other scheme are refused.
- No bridge from a page into the app: no `addJavascriptInterface`, file and content access off, mixed content never, no third-party cookies, no geolocation.
- Every permission request (camera, microphone, MIDI, protected media) is denied; geolocation prompts answered no.
- A certificate error cancels the load; it is never overridden.
- One view: `target=_blank` loads in place, no pop-up windows.
- A download is never saved by VRG Mobile: after a yes it is handed to the phone's browser.
- The log gets only an origin (`https://host`), never a path, a query or a console message.

## Links

`vrg://web` opens the Böngésző where it was left; `vrg://web?u=<address or words>` opens or searches it;
`vrg://web?q=<words>` searches with the chosen engine.

## Data

`filesDir/web/links.json` (`vrg.web-links` v1, written atomically). ⚙ → Export writes the same file through the phone's
"save as"; the VRG Böngésző reads it (Könyvjelzők → Betöltés; opened in the Asztal, START W → B, what it loads goes on to the Asztal's own `web.json`), and so does the Data Vault's browser-kit.
Import merges (a row is never lost). Előzmények mentése can be switched off; Böngészési adatok törlése wipes cookies,
cache, page storage and history and keeps the bookmarks.

## Phone check (⏸)

1. Home → Egyéb → Böngésző: the start panel. Type `index.hu` → opens over https; `192.168.1.1` → http (the router).
2. `NYM-J 3x2,5 !tme` → TME's search; `!w Ohm-törvény` → Hungarian Wikipedia.
3. A link with `?utm_source=x` typed in → opens without it.
4. ☆ on a page → ★; ☰ → Könyvjelzők lists it; × removes it.
5. A page asking for the camera or location (e.g. a webcam test page) → nothing is granted, no prompt.
6. `https://expired.badssl.com/` → does not open; the note says why.
7. A PDF datasheet link → "Letöltés a böngészővel" → the phone's browser downloads it.
8. ⚙ → Export → a `.json` file; on the PC the VRG Böngésző in the Asztal (START W → B) → Könyvjelzők → Betöltés reads it, and the rows appear in the Asztal's Böngésző pane.
9. Kommand: type `tme.eu` → opens here. Alkalmazások → VRG Böngésző → open a search result → opens here.
10. Back steps back in the page history, then leaves to the home.
