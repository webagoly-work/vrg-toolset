# M23 · PC ablakok (`pcwin`): the PC's work folders, read-only, through the relay

**Goal.** With a paired PC, the Desktop's **files** window on the phone: the work folders read-only, a look at a file,
and a copy through M12 Átadás. Map: `../PARITY.md` (units 11, 18–20, 24–26). Built 2026-11-12, **BETA**.
Decisions: D-17 (work roots only), D-18 (the feed stays on the PC), in `../DECISIONS.md`.

## Build

- **The relay** (`Planner/projects/varler-planner/tools/relay-files.js`, wired in `phone-relay-server.js`): three
  messages, trusted (paired) phones only, and **off unless the relay runs with `--files`** (`RELAY_FILES=1`;
  `Mobile\mobile.cmd relay` now passes it):
  - `files.list {}` → the roots; `{h}` → that folder; `{place}` → a Desktop unit's folder (Munkák → `Full\jobs`,
    BRIDGE → `Full\BRIDGE`, Workflow Kit → `Full\Varler_Workflow_Kit`). Folders first, then files, at most 400 rows,
    with the crumbs from the root;
  - `files.read {h}` → a look: text (the first 64 KB, UTF-8 or Windows-1250, as the Desktop's `fsview.js`), an image
    (png / jpg / gif / webp up to 1 MB, base64), else `binary` and nothing sent;
  - `files.copy {h}` → the file onto the Átadás board (M12) as a PC entry, through the board's own checked upload path
    (size and SHA-256), so the phone takes it as any board file, and hears the board's `added` event.
- **The roots are the Desktop's** (`Dashboard/config/roots.json`), narrowed by `Mobile/catalogue/files.json` to
  **Repó, VRG Full and Közös** (D-17). Never listed nor reachable: dot-files and secret names (the Desktop's
  `appscheme.js` rule, plus `.env`, `.pfx`, `id_rsa`…), names Windows would read as another (a trailing dot or space,
  `:`), the deny list (`Full\home`, `Full\tools`, `Full\programs`, `Vendor`, and the old `Planner\apps|home|data`), and
  a link or junction that leads out of its root.
- **The rule, as Indítópult's**: the phone never sends a path. Every row carries a **handle** (16 hex) the relay made
  and keeps in memory; the phone sends one back, a place key, or nothing. Each handle is checked again against its root
  when used (a folder moved into a junction afterwards is refused). A relay restart forgets the handles: the phone
  starts again at the roots. Nothing on the PC is ever written, moved or deleted by this.
- **The phone** (`feature-pcwin`, `kit-core/PcFiles.kt`): the crumbs (⌂ / Repó / …, each a step up), the rows
  (▸ folder; a file with its size and time), tap a file → its look (text in monospace, scrolls both ways; an image
  fitted; a binary says so) with **⇄ Átadásra** and then **Átadás ›**. ‹ Vissza steps back: the look, then up one
  folder, then home. A name with a path separator or a control character is dropped by the parser.
- **In the Asztal**: the ◣ menu and Kommand open Munkák, BRIDGE and Workflow Kit at their own folder, Fájlok at the
  roots; in Lapok the Desktop's `files` pane is this window (`pane:files` → `feat:pcwin`), so the Áttekintés preset
  now has Home and the files strip along the bottom.
- **Mail, feed, search** (D-18): the feed's presets run inside the Desktop on the PC, so the unit is `no` like Posta;
  Belső keresés is `no` for now (Later). Terminal and git are dev level and stay off the phone.

## Telefonon ellenőrizni

0. On the PC: `Mobile\mobile.cmd relay` (now with `--files`); the banner says „A PC munkamappái a telefonon: BEKAPCSOLVA”.
1. PC ablakok tile → three roots: Repó, VRG Full, Közös (OneDrive) — no Asztal, Dokumentumok, Letöltések.
2. VRG Full → jobs, BRIDGE, … are there; `home`, `tools`, `programs` are not. Repó → no `.git`, no `.env`.
3. Open a client job folder → its files with sizes; tap a `.txt` / `.md` → the text; tap a photo → the photo.
4. Tap a PDF → „Ezt a fájlt a telefon nem mutatja” → ⇄ Átadásra → „A táblán: …” → Átadás › → the PDF is on the board;
   take it and open it on the phone. On the PC the original is untouched; the board folder has a copy.
5. The crumbs: tap „VRG Full” → back there; ‹ Vissza steps up one folder at a time, then home.
6. ◣ menu → Munkák → opens straight in `Full\jobs`; Fájlok → the roots.
7. Lapok → preset Áttekintés → Home on top, the files strip below.
8. A relay started without `--files` (START G): the screen says how to turn it on; an unpaired phone is asked to pair.
