# M29 · Kamera: photos with a purpose, the shot list and markup

**Goal.** The user: strengthen the camera — another thing the electrician has at hand all the time — with the most
useful modules for this work, quick to reach for a given purpose (the outskirts, the building itself…). Grounded in
`docs/research/2026-11-18_field-survey-camera-notes.md` ("build now" list). BETA, 2026-11-18. D-32.

## Build

- **◉ on every front**: tap = the camera app for the current purpose (its symbol on the button); **hold** = choose the
  purpose first (13: Épület kívülről, Környék, Hozzáférés, Mérőhely, Elosztó, Meglévő szerelvény, Tervezett hely,
  Hiba, Típustábla, Nyomvonal, Szoba → Fotópont, Dokumentum, Egyéb).
- Each photo (`Capture`) gets its purpose, the room in focus, the shot-list item it was taken for, the time and the
  **GPS from the photo's own EXIF** (when the camera app writes it).
- **The Kamera front** (`CameraFront.kt`): the purposes as tiles (with counts); **Képlista**, the shot list that grows
  with the job (27 items in the kit: building, access, meter closed / open / label / main fuse, board closed / open /
  circuit list / FI label / earthing / free DIN space, the fault, a Fotópont per bathroom and kitchen, the EV charger's
  place, parking, cable route, the roof and shading for solar…): ✓ when done, have/need; a tap shoots for it. A photo
  of the same purpose taken without the list fills the first item still short. **⟳ Sorozat**: the camera comes back
  after each shot until one is cancelled. The gallery by purpose.
- **The photo viewer**: the picture upright; **✎ Jelölés**: arrow, circle, line, freehand, text, five colours, ↶ —
  kept as vectors over the untouched original; the purpose and the room re-chosen; the caption typed or **dictated**;
  the board file name; Törlés.
- **Export**: each photo as `<felmérés>_<C id>_<cél>.jpg`, a marked one also burned in as `…_jel.jpg`, with the
  package (Átadás → PC-re puts each on the board).

## Telefonon ellenőrizni

1. ◉ (koppintás) bármelyik nézetből: kamera → a fotó az aktuális céllal; ◉ tartva: a célválasztó.
2. Kamera nézet → Képlista: Munkakör → E-autó után megjelennek a töltő képei; egy koppintás → kamera → ✓.
3. ⟳ Sorozat be: három fotó egymás után ugyanazzal a céllal; a kamerából fotó nélkül kilépve „Sorozat vége”.
4. Egy fotó → ✎ Jelölés: nyíl, kör, szöveg; ↶; Bezár és újranyitás: a jelölés megvan.
5. Felirat diktálva; szoba átállítva; a Rendezés → Küldés után a PC táblán a `_jel.jpg` is ott van.
6. Helymeghatározással készült fotón a viewer koordinátát mutat.
