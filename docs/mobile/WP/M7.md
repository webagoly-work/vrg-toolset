# M7 · Hálózat (`net`): Bluetooth, WiFi relay, hotspot, tethering

**Goal.** One screen for every way the phone links to the PC and the internet, with honest limits.
**Research first.** Android restricts most of this, so the first deliverable is
`docs/mobile/research/M7-network.md`, recording what an ordinary (non-system) app can do on Android 9–15. Ask
the user before building past it.

## Known limits (verify in the research)

- **Hotspot**: an app cannot turn on the regular tethering hotspot (system permission). It *can* open the
  tethering settings directly, read whether tethering is on (the tether-state broadcast / `ConnectivityManager`),
  and start a `LocalOnlyHotspot` (WiFi with no internet: enough for phone ↔ PC relay on a site with no router).
- **Usage notification**: while tethering is on, a foreground service watches `TrafficStats` mobile bytes and
  posts "Hotspot: 1.2 GB ma". There is a user-set warning threshold. Exact per-client numbers are not available.
- **USB tethering / Bluetooth tethering**: not switchable by an app. Detect the state, deep-link to the right
  settings page (vendor differences: test Xiaomi, Sony, Pixel), and explain the one tap needed.
- **BT HID**: Légegér's status (supported, registered, connected host) shown here as well, with a link to it.
- **Phone as the relay** (D-9): if A, a small WebSocket server in the app (Ktor-server-cio or NanoHTTPD),
  speaking the same envelope as `phone-relay-server.js`. The PC apps already look for a relay on a list of
  addresses, so add a way to point them at the phone (Kódváros `36-link.js` and Planner `07a-link.js`).
