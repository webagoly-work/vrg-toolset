# M6 · Gyorsjegyzet (`notes`): notes into the chat-log branch

**Goal.** Type, dictate or share a note on the phone, and it lands in a dedicated branch of the repo that acts
as the project's chat log. Sessions and the user can read it from anywhere. Answer D-6 first. The recommended default is A:
branch `mobile-log`, one file per day `log/YYYY-MM-DD.md`.

## Build

- `kit-core`: the note model and its Markdown line
  (`- 14:32 · [planner] szöveg… (from: phone, branch: <active branch>)`), plus the append rule (read the day file + sha,
  append, PUT with sha; on a 409 / sha mismatch, re-read and retry up to 3 times). Tests.
- `kit` GitHub client: contents GET / PUT, and creating the `mobile-log` branch from `main` if it is missing
  (`POST /git/refs`). Never write to any other branch: the branch name is a constant, and the client refuses others.
- `feature-notes`: a text field with 🎤 dictation (hu-HU), a tag picker (the tools from M4's map), an
  outbox that queues offline and sends when online (WorkManager), and today's log read back.
- Share target: "Megosztás → VRG Mobile" with text from any app creates a note.
- `vrg://notes/new?text=…` (already routed by `Links`) pre-fills it.

## Tests (cloud)

The Markdown format, the append-with-retry logic against a fake API (conflict once, then OK), the outbox order.

## Telefonon ellenőrizni

- [ ] A note appears in `log/<today>.md` on the `mobile-log` branch within seconds. Offline notes go out when online.
