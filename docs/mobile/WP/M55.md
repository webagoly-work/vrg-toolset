# M55 · Térkép-feed (in `map`): the nearest useful places around you

**Goal.** The Founder, 2026-11-21: the Térkép as a Waze-like companion, starting with a "Map feed": around the user's
position, 5–6 places preset by the user (Otthon, the closest Daniella, szerelvény / villamossági / barkácsbolt, a
"Korean type" general store, a market like Aldi or Spar, a restaurant / büfé, a public toilet, a hospital or medical
unit, public transport), each by proximity, with an ETA and a ghost line from the user to its icon; hold (RCO) one to
select it, the others hide, and the user and that place appear as a "spider". Asked as decisions and answered the same
day: D-129 (N2 routing: our own offline road network), D-130 (traffic later, opt-in), D-131 (points from OSM, own pins
on the phone), D-132 (stops now, BKK live departures later). Built in a cloud session as **N1**, **BETA**.

## Build

It is a layer of the VRG Térkép page, so the PC and the phone (M43) get the same thing: `docs/map/FEED.md` says what it
does and how. In short:

- `Map/lib/feed.js`: the categories, the OSM matching, nearest, distance, ETA (straight line × detour ÷ speed).
- `Map/lib/feed-layer.js`: the **Feed** button (key **F**), the cards, the icons, the ghost lines, hold / right-click
  to select (the spider), Navigáció (on the phone: the M43 `vrg-map:nav` hand-off, coordinates and the label only),
  ⚙ (categories, Otthon, own pins in the page's storage, D-31).
- `Map/tools/build-pois.js` (+ `Map/tools/osm-pbf.js`): `Map/data/pois.json` from the OSM extract, all of Hungary;
  `fetch-data.js --only=pois`.
- On the phone: `MapPhone.PAGE_FILES` gained the two scripts, and `pois.json` is kept like the address index, so the
  feed works offline once the phone has opened the map paired with the PC. `MapPhoneTest` checks every script the page
  loads is kept.

## Tests

`node Map/test/run.js` (75 green): `feed.test.js` (rules, build-pois on a real .pbf written by `pbf-writer.js`) and
`feed-page.test.js` (headless Chromium, the real MapLibre, a faked GPS). The kit-core tests (MapPhoneTest 13) green. The
real page was opened at 1100 px and 375 px with a stand-in data file: no page errors, the list and the spider lay out.

**Not verified here (cloud session):** no OSM extract (Geofabrik is blocked here), so `build-pois.js` ran only on the

in the WebView, holding on a touch screen and the navigation hand-off are checked below.

## Telefonon ellenőrizni

0. A PC-n egyszer: `node Map\tools\fetch-data.js --only=osm,pois` (vagy START → M az első indításkor), majd a START
   M szervere (H) fut, a relé `--ports`-szal.
1. VRG Térkép (párosított PC-vel, „PC adat”) → **Feed** gomb → alul a lista: Otthon (nincs beállítva), Daniella,
   Szerelvény/barkács, Élelmiszerbolt, Étkezés, Kórház/orvos; mindegyiknél név, „~N perc” és távolság. A fejlécben
   „a helyedtől (±… m)”: az Android helyengedélyt kér, ha még nem adtad meg.
2. A térképen ugyanennyi ikon, mindegyikhez szaggatott vonal a kék pöttytől.
3. ⚙ → Otthon: „a helyem” → az Otthon kártya kitöltődik. ⚙ → kapcsold ki az Étkezést, be a WC-t → a lista
   átrendeződik; egy hetedik bekapcsolása üzenetet ad.
4. **Koppints** egy kártyára → a térkép mutatja a helyed és azt a pontot; nincs kiválasztás.
5. **Tartsd nyomva** az Élelmiszerbolt kártyáját (vagy az ikonját) → rezdül, a többi eltűnik, egy vastag vonal köt
   össze vele („pók”), a kártyán Navigáció és ✕ Vissza. **Navigáció** → a navigációs app a ponttal nyílik.
   ✕ Vissza → minden visszajön.
6. Sétálj 30–50 métert → a távolságok frissülnek. 🚗 Autó → 🚶 Gyalog: az idők nőnek.
7. Repülő üzemmód, majd újra Feed → a lista ugyanúgy (a pontok a telefonon vannak), a saját pontok is.
8. ⚙ → „+ Daniella” a térkép közepén → saját Daniella; a listában, ha közelebb van, mint az OSM-es. A ✕ törli.
