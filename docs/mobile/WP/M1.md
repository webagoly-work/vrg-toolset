# M1 · Beállítások (`settings`): the shell's own settings

**Goal.** The app has settings of its own, not borrowed from Légegér: the look, an About page with
a log, and the list of paired PCs (filled in by M2).

## Build

1. `kit`: a `ShellSettings` store (SharedPreferences + `StateFlow`, the same pattern as Légegér's
   `SettingsStore`): `palette`, `uiScale`, `startInLast` (D-5 default true), `pairedPcs` (empty until M2).
   Pure data class and (de)serialisation in `kit-core`, with tests.
2. **Move the look out of Légegér.** `ShellActivity` applies `Melyviz.palette` and the UI scale for every
   feature. Légegér's ⚙ → Megjelenés section either shows the shell's controls (through `host.open("settings")`)
   or keeps only Légegér-specific items. Migrate an existing Légegér palette value once.
3. `feature-settings` module (or inside `app`, if small): sections Megjelenés · Párosított PC-k · Névjegy
   (version, build, commit SHA once M9 stamps it, open-source notices) · Napló (the last 200 log lines from a
   small `kit` logger every feature uses).
4. A header ⚙ on the home screen, as well as the tile.
5. Catalogue: `SETTINGS` → BETA. Registry line.

## Tests (cloud)

`kit-core`: settings round trip, the palette migration rule, and that an unknown palette falls back to Mélyvíz.

## Telefonon ellenőrizni

- [ ] Napló shows Légegér's connect and disconnect lines.

**Done when** the look is owned by the shell and Légegér has no palette setting of its own.

## Status (2026-10-29, cloud session)

Built, catalogue stage **BETA**. What went where:
- `kit-core`: `ShellPrefs` (data, storage map, `Look` fallback and clamping, the one-off `adoptLook`), `PcCodec`
  (paired PCs as one string), `LogBook` (200-line ring); tests in `ShellPrefsTest`.
- `kit`: `ShellSettings` (SharedPreferences `shell_settings` + `StateFlow`), `VrgLog` (Napló + Logcat),
  `ui/Parts.kt` (section title, chip, toggle, slider, palette row).
- `feature-settings`: `SettingsFeature`. `ShellActivity` applies palette and size to every screen and honours
  `startInLast`; the home header has a ⚙. The APK carries its commit (`vrg.gitSha` meta-data from `GITHUB_SHA`).
- Légegér: `palette` / `uiScale` removed from `DeckSettings`; `takeLegacyLook()` hands the old values to the shell
  once. Its ⚙ → Megjelenés shows the look and opens Beállítások. Bluetooth and relay connect / disconnect go to `VrgLog`.

**Not verifiable in the cloud:** the Android modules compile only in GitHub Actions; the look, the migration
on a phone that had Légegér settings (only `hu.vrg.mobile` installs count: D-1), and the Napló lines need the phone.
The Napló is in memory, so it starts empty after the app process is killed.
