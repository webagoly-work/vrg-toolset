# M3 · GitHub fiók (`account`): sign in, and the shared GitHub client

**Goal.** The phone signs in to GitHub once (D-2 = A, the device flow). Every online feature
(M4, M5, M6, M9, M10) uses one shared client from the kit.

## User step (before the build can be tried; the session cannot do it)

Create a GitHub **OAuth App** (github.com → Settings → Developer settings → OAuth Apps → New): name
"VRG Mobile", homepage any URL, **Enable Device Flow** ticked. Put its **Client ID** (public, not a
secret) into `Mobile/android/kit/src/main/res/values/github.xml` as `github_client_id`. There is no client
secret: the device flow needs none. Scopes: `repo` (the toolset repo is private) and `notifications` (M10).
A GitHub App with fine-grained permissions would be narrower. Mention that as an option, and keep the OAuth
App unless the user prefers otherwise.

## Build

- `kit-core`: `GitHubApi` request and response models (device code, token poll with `slow_down` /
  `authorization_pending` / `expired_token` handling, rate-limit headers), with JSON parsing done in `kit-core` so it is
  tested on the JVM (org.json as compileOnly, as airdeck-core does, or kotlinx-serialization).
- `kit`: `GitHub` client on OkHttp (already a dependency of Légegér): token from the Keystore-backed store,
  `GET /user`, a small typed wrapper per endpoint later WPs need, and ETag caching (conditional requests do not
  count against the rate limit).
- `feature-account`: a "Belépés" screen that shows the code big and copyable, opens
  github.com/login/device in a Custom Tab, polls, then shows avatar + login + repo access check
  (`GET /repos/webagoly-work/vrg-toolset`). Sign out deletes the token.
- The repo (`webagoly-work/vrg-toolset`) is a constant in one place in `kit-core`, not scattered.

## Tests (cloud)

The device-flow state machine against recorded JSON fixtures: pending, slow_down (interval +5 s), expired, denied,
success. The rate-limit parser. **Never** call the real GitHub from tests.

## Telefonon ellenőrizni

- [ ] Sign in with the code. Survives a restart. Sign out removes access.
- [ ] Airplane mode: a clear "nincs internet" message, no crash.
