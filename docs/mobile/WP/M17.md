# M17 · Rétegverem (`stack`): the VRG Stack's 3D pages on the phone

**Goal.** The user's words (2026-11-07): *"this whole feature should also be in the VRG App, with proper touch
control, gestures, etc."* The feature is the VRG Stack's two 3D views from `H:\VRG\Full\notes\stack`:
the **Konnektóm** (the stack as a brain, placed by function in its parts; 2 KB nodes, axiom neurons, tracers) and
the **Holo** page (Polip, Gömb, Föld, Mag, the Őrség lock). Decision D-12 (below) records how they reach the phone.

## Build (D-12)

- **PC side**: `Mobile/stack/publish-stack.js` bundles each page into one self-contained HTML file (Mélyvíz CSS,
  `brain.js`, `touch.js`, `earth-land.js` and the data `out/connectome-data.js` inlined, `window.STACK_BUNDLE = true`)
  and publishes `stack/{konnektom.html, holo.html, meta.json}` on the orphan branch **`stack-pages`**: git plumbing
  only, one root commit per publish, `--force-with-lease` on that branch alone (the same rule as `city-pages`).
  Without `--push` it is a dry run. START → R Rétegverem → **T Telefonra** runs it with `--push`.
  `.github/workflows/mobile-city.yml` ignores `stack-pages`.
- **Phone**: `kit-core/Stack.kt` (`StackPages`, `StackMeta`, `StackSync.decide`; tested in `StackTest`) and the
  module `feature-stack` (`StackFeature`): chips Konnektóm / Holo, ⟳ checks `stack/meta.json` through `GitHub.get`
  and downloads both pages through the contents API (`Accept: application/vnd.github.raw`) only when the publish
  changed; each download goes to `.part`, is checked against the meta's size, then renamed; the meta is written last.
  Copies in `filesDir/stack/` (offline opens the last one with "· offline"). The WebView is M5's: JS + DOM storage on,
  file / content access off, served from `https://appassets.androidplatform.net/stack/<file>`, every other request
  an empty 403; a crashed renderer is dropped and reported.
- **Touch** is in the pages themselves (`notes/stack/touch.js`), so it also works in a phone browser:

| Gesture | Konnektóm | Holo |
|---|---|---|
| one finger drag | orbit | orbit |
| pinch | zoom | zoom |
| two-finger twist | turn | turn |
| two fingers up / down | tilt | tilt |
| tap | pick + tip | pick + tip; an entry point (Mag) focuses its line |
| double tap | reset the view | reset the view |
| long press | select, scroll to the card | on a node: select; on empty space: Őrség lock on / off |
| two-finger swipe left / right | — | next / previous form |

  Mouse input is untouched (touch.js takes only `pointerType: 'touch'`, in the capture phase).

## Telefonon ellenőrizni

1. Kezdőlap → Munka → **Rétegverem**: GitHub belépéssel ⟳ letölti a két oldalt (a sorban a dátum és a méret).
2. Konnektóm: egy ujj forgat, csippentés nagyít, két ujj csavarás fordít, koppintás kiválaszt, dupla koppintás alaphelyzet, hosszú nyomás a kártyához görget.
3. Holo: két ujjas söprés balra / jobbra formát vált (Polip → Gömb → Föld → Mag), Mag-ban koppintás a belépési pontra kiemeli a pályát, hosszú nyomás üres helyen zárja / nyitja az Őrséget.
4. Repülő mód: a Rétegverem a legutóbbi változatot mutatja „· offline” jelzéssel.
5. A PC-n START → R → T után a telefonon ⟳ az új változatot tölti le.
