# M2 · QR párosítás (`pair`): scan the PC's QR, become a trusted phone

**Goal.** One scan connects the phone to the PC relay and makes it **trusted**. Today any device on
the WiFi can introduce itself as a phone. After M2, the relay serves PC-acting abilities (screenshots,
and later M8 ports, M11 launch, M12 drop) only to a paired phone.

## The handshake

1. The PC shows a QR at `http://<pc>:47291/pair` (a page the relay serves, also linked from Kódváros /
   the Planner's phone dialog): `vrg://pair?ws=ws://<lan-ip>:47291&c=<one-time code>&n=<pc name>`.
   The code is 128-bit random, valid for 2 minutes, single use, and printed on the relay console.
2. The phone scans it (in-app scanner, or the system camera via the `vrg://` link), connects, and sends
   `{type:'pair', payload:{code, device, pub}}`. `pub` is a public key the phone generated in the Android Keystore.
3. The relay checks the code and stores `{device, pub, added}` in a file outside the repo
   (`%LOCALAPPDATA%\VRG\relay-paired.json`). It answers `{type:'paired', payload:{pc, id}}`.
4. On later connects the phone signs the relay's `challenge` (sent in the hello answer) with its key. The relay
   marks the connection trusted. A key that is not on the list stays an ordinary, untrusted phone.

## Build

- **Relay** (`phone-relay-server.js`, or a `relay-pair.js` module it requires): `/pair` page with the QR
  (generate it locally, without a CDN; a small vendored QR encoder is fine, recorded in vendor-manifest if
  fetched), the code store, `pair`, challenge / response, a `trusted` flag on the client, and `--shots` requiring
  trusted. Keep everything backwards compatible: an unpaired phone-sender.html still works for control.
- **`kit`**: lift Légegér's `RelayClient` + `Discovery` into a shared `kit` relay link (Légegér then uses
  it), adding the key handling. `kit-core`: pair payload builders, QR content parser (`Links` already
  routes `vrg://pair`), with tests.
- **`feature-pair`**: a scanner screen with CameraX + ML Kit barcode scanning (bundled model, works offline;
  ask before adding the Play-services variant). Also "scan with the camera app" help, and the result:
  PC name, trusted ✓. Paired PCs land in M1's list, where a PC can be removed.
- Légegér's ⚙ "Keresés" gets a "QR beolvasása" button → `host.open("pair")`.

## Tests (cloud)

- Node, in `Mobile/tests/relay-pair.js`: code expiry, single use, a wrong code is refused, the
  challenge signature verifies (use Node's crypto with the same curve as Android, P-256 / SHA256withECDSA),
  an untrusted phone asking for a screenshot gets `nack`, and phone-sender.html still controls the Planner.
- Kotlin: the QR parser, the payloads, signature format compatibility (a JVM ECDSA signature verifies with a Node fixture).

## Telefonon ellenőrizni

- [ ] Scan from the PC screen → connected and trusted in under 3 seconds.
- [ ] After a relay restart the phone is still trusted. After "remove" on the phone or the PC it is not.

**Security note.** The QR is shown only on the PC's own screen. The code never travels by anything else.
