# M30 · Helyszín: the address, VRG Térkép, and the building against the sketch

**Goal.** The user: a job's address can be typed and used to plug in an embedded **VRG Map** window — not just to show
it, but to give the system geolocation, including **comparing the sketch to the outer dimensions and position of the
building** at the address for cross-referencing. BETA, 2026-11-18. D-31.

## Build

- **Helyszín** (`SiteFront.kt`): the address (saved with ✓); **⌖ Itt vagyok (GPS)**: the phone's own position
  (permission asked once; nothing is sent anywhere); the coordinates and their source.
- **VRG Térkép (the PC's offline map)**: with a paired PC and the relay run with `--ports`, the page opens embedded
  (`/vrg-terkep.html?embed=1`, at the coordinates or searching the address) through M8's port proxy; **⇣ Átvétel a
  térképről** takes the map's centre (its `#zoom/lat/lon` hash) as the job's position. Without the PC it says why.
- **On the internet, only on the buttons**: 🔎 *Cím keresése* (OSM Nominatim: the address only, Hungary) and
  ▱ *Épület körvonala* (Overpass: the coordinates only → the building the point is in, else the nearest within 40 m).
- **The building against the sketch** (`SiteMath`): the outline measured as an oriented rectangle (a house standing
  at 17° still reads 12,4 × 9,8 m), the solved sketch measured the same way: **egyezik** (±8 %), **kisebb** (a flat in
  a bigger building, or a missing part), **NAGYOBB** (a size is wrong — check the measures).
- The Desktop page shows the same footprint and embeds VRG Térkép at `localhost:8802`.

## Telefonon ellenőrizni

1. Helyszín → cím → ✓; ⌖ Itt vagyok: engedély, koordináta „a telefon helye”.
2. Párosított PC, `Mobile\mobile.cmd relay` (--ports), START → szerver H: 🗺 Megnyitás → a ház a térképen; mozgasd,
   ⇣ Átvétel → „VRG Térkép”.
3. 🔎 Cím keresése → lista → egy sor → koordináta „OSM keresés”.
4. ▱ Épület körvonala egy családi háznál: méret m-ben, és mellette a vázlathoz mért „egyezik / kisebb / NAGYOBB”.
   Egy méretet szándékosan elrontva: „NAGYOBB”.
