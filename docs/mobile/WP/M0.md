# M0 · The shell + Légegér as a feature (done 2026-10-29)

Built on branch `claude/gracious-pasteur-vakjwf` (PR #2):

- `Mobile/android` is one Gradle build with the modules `kit-core`, `kit`, `airdeck-core`,
  `feature-airdeck` and `app`, plus a JVM-only mode (`VRG_JVM_ONLY=1`).
- `kit-core`: `Catalogue` (13 features, ids, WPs, stages, needs) and `Links` (vrg://, vrgdeck://, Planner QR), with 5 tests.
- `kit`: Mélyvíz moved here from Légegér. `VrgFeature` / `FeatureHost`.
- `app`: `ShellActivity` (one Activity: home or a feature, Back → home, links, keys, foreground,
  system bars from the palette, keep-screen-on undone on leave), `HomeScreen` (tiles grouped,
  stage badges), `PlannedScreen` (blurb + WP + needs), `Registry`.
- `feature-airdeck`: the old app. MainActivity became `AirDeckFeature`, and the old Application class is gone
  (`Deck.init` runs from the feature's `init`). Bluetooth starts the first time Légegér opens.
  The notification opens `vrg://airdeck`. The gyro is no longer `required` in the manifest, so the app installs on any phone.
- Launchers: `Mobile\mobile.cmd` (START → L). GitHub Actions builds the APK.

Checked on the PC: `assembleDebug` OK, 29 Légegér + 5 kit-core tests green, JVM-only mode green with
no Android plugin on the classpath, `check-start` OK.
