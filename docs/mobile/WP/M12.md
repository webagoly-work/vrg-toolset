# M12 · Átadás (`drop`): phone ↔ PC transfer

**Goal.** Get things from the phone to the right place on the PC, and back:
- photos (site pictures for the Planner, labels for the Inventory);
- files (a supplier PDF received on the phone);
- the clipboard (both ways);
- Légegér's screenshots, which already come PC → phone.

This uses the relay and needs M2 pairing.

## Build

- **Relay**:
  - `POST /drop` (trusted phones only, size limit 50 MB, streamed to disk) → saved to `<HROOT>\_inbox\phone\<date>\`,
    outside the repo. Client PDFs must never land in the repo (CLAUDE.md: `*.pdf`).
  - `{type:'drop', payload:{name, bytes, target}}` announces it, and the target app picks it up:
    - `planner`: the existing `07b-phone-camera.js` photo path, into the open job;
    - `inventory`: the import queue;
    - `inbox`: just the folder.
  - `clip.set` / `clip.get` (text only) between the phone and the PC clipboard (PowerShell `Set-Clipboard` / `Get-Clipboard`).
- `feature-drop`: a share target ("Megosztás → VRG Mobile → PC-re"), a picker, a target choice, progress, and a history
  list. A camera button takes a photo straight to the Planner.
- Reuse Légegér's `ShotStore` for PC → phone files (move it to `kit` if both use it).

## Tests (cloud)

Node: upload limits, the path stays in `_inbox` (no `..`, no absolute names, the name sanitised), an untrusted phone
is refused, and the clipboard is text only.
