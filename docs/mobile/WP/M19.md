# M19 · Asztal (`desk`): the VRG Desktop's frame on the phone, plus the orientation toggle

**Goal.** The user's words (2026-11-12): VRG Mobile should "seem, feel and function as much as it can as the Desktop
experience is", a simplified Desktop and not only a companion, with "a manual toggle to change screen orientation".
Map: `../PARITY.md` (units 1–5, 8, 23, 27, 28, 33 and the frame parts). Built in the night run of 2026-11-12, **BETA**.
Decisions D-14, D-15 (`../DECISIONS.md`).

## Build

- **The Desktop's catalog on the phone, generated.** `Mobile/catalogue/desk-gen.js` reads `launcher/vrg-catalog.json`,
  takes every `level: "user"` unit (34) and writes `kit-core/.../DeskCatalog.kt`: id, hu / en name, the Desktop group,
  its icon, and how it reaches the phone (`Reach`: NATIVE / WEBAPP / PC / NONE, the same table as PARITY.md). A new
  user unit on the Desktop with no line in its `REACH` table fails the generator. `mobile.cmd test` runs
  `desk-gen.js --check`.
- **Kommand** (`kit-core/Kommand.kt`): `fold`, `words` and `search` are `Dashboard/shell/lib/palette.js` line by
  line (every query word a prefix of a word in hu + en; rank by word position, then recent use, then index order).
  The proof is a fixture: `desk-gen.js` runs the palette's own `search()` on the Desk catalog with 25 queries and
  writes the answers to `Mobile/tests/fixtures/kommand.json`; `KommandTest` replays them against the Kotlin port and
  must get the same ids in the same order. The phone's index adds its own features (`feat:`) and the open windows
  (`win:`); units it cannot open (`Reach.NONE`) are not offered. A query that is a web address offers
  "Megnyitás a böngészőben" (the Desktop's `web` window = the phone's browser). Recent use is kept in
  `ShellPrefs.kommandRecent` (30, like the palette).
- **The frame** (`app/DeskScreen.kt`): the top strip (the sheet tabs slot, filled by M20; the Kommand field; the
  orientation button; ⚙), the sheet area (the home window until M20: the phone's features as desktop icons,
  4 columns upright, 8 lying down), the dock (◣ menu dial, the open windows newest first, ◢ Rétegverem dial).
  ◣ lists the Desktop's catalog in the Desktop's groups (Munka, Alkalmazások, Fájlok, Rendszer, Fejlesztés), with a
  tag per unit (web / PC / —); what the phone cannot open is dimmed, not hidden. A tap goes to
  `ShellActivity.openUnit`: a feature opens, a WEBAPP unit opens M21 Alkalmazások with the app id, `port:<n>` opens
  M8 Localhost, Posta opens the phone's mail app, the rest says why not.
- **The Asztal is the shell, not a feature module**: it is the home. `Registry.shellParts` counts it as built;
  `open("desk")` goes home (and from Kompakt makes the Asztal the home again).
- **Kezdőlap** (`ShellPrefs.home`): Asztal (default) / Kompakt (the tile home as it was), in Beállítások → Indulás.
  "Irányítópult nézet" in the ◣ menu shows the Kompakt home once, Back returns.
- **Tájolás** (`ShellPrefs.orientation`): the top strip's button cycles Automatikus → Álló → Fekvő and Beállítások →
  Indulás has the same three chips. Applied with `setRequestedOrientation` (FULL_USER / PORTRAIT / SENSOR_LANDSCAPE).
  The manifest no longer locks portrait and handles the rotation itself (`configChanges`), so a rotation does not
  restart the Activity: the WebViews (Kódváros, Rétegverem, Archívum) and the relay link survive it.

## Tests

`KommandTest` (7: the palette's answers on 25 queries, folding, the generated catalog, the index, every target,
recent + URLs, the two settings and their storage) and `DeskCatalogueTest`. No Compose previews or Robolectric in this

## Telefonon ellenőrizni

1. After the update the home is the **Asztal**: top strip, icons, dock with ◣ and ◢.
2. ◣ Menü: the five groups; Varler Planner → Alkalmazások (PLANNED tile until M21 is on the phone); VRG Térkép →
   Localhost; Posta → the phone's mail app; VRG Mobile → "ez maga a telefon".
3. ◢ opens Rétegverem. A feature opened from an icon appears in the dock; Back returns to the Asztal.
4. Kommand: "led" → LED árkalkulátor first; "legeger" → Légegér; "claude.ai" → "Megnyitás a böngészőben"; the
   keyboard's Go runs the first hit; ✕ and Back close it. A used hit comes first next time with an empty query.
5. The orientation button: ▯ Álló → ▭ Fekvő (the phone turns to landscape and stays) → ⟳ Automatikus (follows the
   phone) → back to Álló. The icon grid has 8 columns lying down. Same three chips in Beállítások.
6. Lying down: Légegér, Képernyő, Kódváros, Archívum still usable (Légegér's gyro was made upright: check its axes).
7. Beállítások → Kezdőlap: Kompakt brings the old tile home back; its Asztal tile switches back.
8. TalkBack: the dials read "Menü" / "Rétegverem", the orientation button reads its state.
