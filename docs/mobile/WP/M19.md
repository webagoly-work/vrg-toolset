# M19 · Asztal (`desk`): the VRG Desktop's frame on the phone, plus the orientation toggle

**Goal.** The user's words (2026-11-12): VRG Mobile should "seem, feel and function as much as it can as the Desktop
experience is", a simplified Desktop and not only a companion, with "a manual toggle to change screen orientation".
Map: `../PARITY.md` (units 1–5, 8, 23, 27, 28, 33 and the frame parts).

## Build

- The home becomes the **Asztal**: a top strip (sheet tabs, the Kommand field, the orientation toggle), the sheet
  area, a dock with the open windows, and the two corner dials: ◣ menu (the catalog at User level, grouped as on the
  Desktop) and ◢ Rétegverem (M17). The tile home stays as **Kompakt** (Beállítások → Kezdőlap: Asztal / Kompakt).
- **Kommand** (`kit-core/Kommand.kt`): one search over the catalog, the features and the open windows, with the
  Desktop palette's scoring (`Dashboard/shell/lib/palette.js`) ported line by line.
- **Orientation** (`ShellPrefs.orientation`): Automatikus → Álló → Fekvő, applied with `setRequestedOrientation`.
