# M4 · Haladás (`pulse`): the active branches, fresh

**Goal.** One screen answers "where does the work stand?". For each active branch (D-8), it shows the last
commits and the open PR with its CI state. It also shows **which tools each branch has patched**: the
toolset's tools (START.cmd's registry plus the apps like VRG Mobile itself), each marked with the branches
that change it, relative to `main`.

## Build

- **Tool map.** `Mobile/catalogue/tools.json` maps a tool to its paths: Planner → `Planner/projects/varler-planner/`,
  Inventory → `Inventory/`, Kódváros → `CodeCity/`, VRG Mobile → `Mobile/`, and so on. Generate it once with a
  Node script from START.cmd's `T<n>_NAME/PATH` (reuse `tools/check-start.js`'s parser) plus a hand-kept list
  for non-page tools. The phone downloads it from `main` (raw contents API), so it updates without an app release.
- `kit-core`: branch → changed files (`GET /repos/{r}/compare/main...{branch}`), files → tools, then the summary
  model, with tests on fixtures.
- `feature-pulse`: branch cards (name, ahead / behind, last commit time + message, PR #, CI ✓ ✗ ●), a tools
  grid (each tool with coloured dots per branch), pull to refresh, ETag-cached.
- A tap on a commit or PR opens it on github.com (Custom Tab).

## Tests (cloud)

Compare-payload → tools mapping. A branch touching two tools. A renamed file. A branch behind main only.
