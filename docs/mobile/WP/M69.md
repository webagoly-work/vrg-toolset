# M69 · VRG Füzet (`notebook`): the malleable notebook, forked from the Sketcher

**Goal.** The Founder, 2026-11-21: "create a fork and make the Note app into this multi-faceted, malleable app". The
Sketcher already has the right position: it is a note taker with modules configured per application (fronts, a catalog
that is pure data, variants that agents write). The fork keeps its engine ideas and drops the survey, so one notebook
holds every kind of day-to-day entry, and each application is a **kit**. Background: `docs/mobile/PERSONAL-APP.md` and
the framework in the session notes (entries · views · actions · rules + extend; the eight directions).

Built 2026-11-21 in a cloud session, **BETA**. The decisions were taken as defaults while building (D-177 … D-181). Revisit
them in `docs/mobile/DECISIONS.md`.

## What was forked, and what was not

| From the Sketcher | In VRG Füzet |
|---|---|
| Every capture is a self-standing record; links may come late | `Entry`: id, kit, type, time, text, fields, tags, links, done, open |
| Completeness is derived, never stored (*Nyitott szálak*) | `Engine.open`: Esedékes, Határérték, Tisztázandó, Hiányzik, Rég volt, Javaslat |
| The catalog is data (`fieldkit.json`); keyword detectors behind the notes | a **kit** is data (`Mobile/notebook/kits/*.json`); keywords suggest a tag or move a note into a kit |
| Variants written by an agent from a phone request (GO VARIANT) | kits written by an agent from a **Kérés** entry (`Mobile/notebook/PROTOCOL.md`) |
| ✎ on every front, nothing half-done is lost | ✎ Jegyzet on the home at all times; the note being typed is kept as the draft |
| One survey file | **one store** for every kit: one search, one export |

Not forked: the floor plan, the solver, the camera fronts and the Planner export. Those stay in the Sketcher, which is
unchanged. A later step could make the survey a kit of its own (D-181).

## As built

- **`notebook-core`** (pure JVM, 24 tests):
  - `Kit.kt`: the kit format and its validation. Seven field kinds; `required`, `due` and `min` / `max`; four view
    kinds (timeline, list, checklist, tally grouped by day / week / month / type / tag / field, with a sum); `stale`
    rules; chips; keywords.
  - `Store.kt`: entries, values, ids that are unique across phones (`E` + base-36 time + 4 random characters),
    tombstones, the read with version check.
  - `Engine.kt`: accent-folded search with `#címke`, the views, the open items, the suggestions and applying them.
  - `Transfer.kt`: export and the merging import (the newer copy wins, deletions hold, importing twice changes nothing).
- **Bundled kits** (`Mobile/notebook/kits`, copied into the APK's assets at build time; `KitTest` validates them all):
  - **Alap** (always on): Jegyzet, Teendő with a deadline, Kérés.
  - **Munka**: Munka with its status; Szigetelési ellenállás (≥ 1 MΩ, MSZ HD 60364-6) and áramvédő kioldási idő
    (≤ 300 ms at IΔn) with their limits; Anyag; Munkaidő. Views: weekly hours, material totals, jobs by status.
  - **Otthon**: Mérőóra with a monthly reminder, Karbantartás with its due date, Bevásárlás.
  - **Kutya**: Séta, Etetés, Súly, Állatorvos; a daily walk reminder. A sample until Personal App Q4 is answered; off
    on the first start.
- **`feature-notebook`**: four places inside one feature. Back walks out of each before leaving the feature.
  - **The home**: search over everything; ✎ Jegyzet plus ＋ for each type of the chosen kit; the kit chips; the kit's
    view chips; the view; one-step undo after a delete.
  - **The editor**: kit and type; text with dictation; an input for each field kind (date with Ma / Holnap / +1 hét /
    +1 hónap); quick chips; tags; Tisztázandó and Kész; the linked entries.
  - **⚑ Nyitott**: Alkalmaz / Megnyitás / Elvet on each item.
  - **⚙ Kitek**: on / off, load a kit from a file, delete an own kit, ✦ Kit kérése (shared and saved as a Kérés),
    Export / Import of the whole store through the system file picker.
- The store is `filesDir/notebook/store.json`, written whole after each change (tmp + rename). A file that cannot be
  read is put aside as `store.bad-<time>.json`, never overwritten.
- Catalogue `notebook` (📓, Munka, BETA, M69), home page 1 between the Sketcher and the Csipogó, a Katalógus page,
  `vrg://notebook/new?text=…` opens the editor with the text.

## What I could not verify here

- The Android module cannot be compiled in the cloud session (Google's Maven is blocked). GitHub Actions compiled it
  and built the debug APK on 2026-11-21 (run 173, after one fix in run 172). No instrumented or UI tests exist for it.
- Nothing was run on a phone: the layout at phone size, the keyboard over the fields, the dictation, the system file
  picker and the share sheet.
- Location is not recorded yet (no permission asked). VRG Térkép and the PC relay are not wired in.

## Telefonon ellenőrizni

1. Kezdőlap → page 1: the "VRG Füzet" card with "Teszt" between the Sketcher and the Csipogó. Tap → VRG FÜZET.
2. ✎ Jegyzet → type "Holnap el kell hozni a létrát" → Mentés. It appears in Alap › Napló under "Ma".
3. ⚑ Nyitott: a Javaslat "legyen Alap › Teendő" for that note → Alkalmaz → it moves to Alap › Teendők.
4. Kit chip Munka → ＋ Ω Szigetelési ellenállás → Áramkör "F3", érték "0,4" → Mentés. ⚑ Nyitott shows Határérték
   "0,4 MΩ, legalább 1 MΩ kell". Change it to 2 → the item disappears.
5. ＋ ◷ Munkaidő 90 and 45 (perc) → Munka › Munkaidő shows "Ez a hét · 2 db · 135 perc".
6. ＋ ▣ Anyag "Dugalj" 4 and "dugalj" 2 → Munka › Anyagok shows one Dugalj line with 6.
7. Otthon › ＋ ⚙ Karbantartás "Kazán", Esedékes → Ma → Mentés. ⚑ Nyitott: Esedékes. Tick it in Otthon › Karbantartás →
   the item goes.
8. Search "kazan" (without the accent) finds it; "#beszerezni" finds entries with that tag.
9. Long note, then leave with ‹ Mégse and come back → ✎ Jegyzet starts with the text (the draft).
10. Delete an entry → "Bejegyzés törölve." → Visszavonás brings it back.
11. ⚙ Kitek → Kutya on → its chip appears; ⚑ Nyitott shows "Ma még nem volt séta". Kutya off → the item goes, the
    entries stay.
12. ⚙ Kitek → Export → save to Letöltések; delete two entries; Import the file → "Nincs új a fájlban." (the deletions
    hold); on a second phone, Import → all entries arrive.
13. ⚙ Kitek → ✦ Kit kérése → the share sheet with the template; Alap › Kérések holds the request.
14. Load a kit file from Letöltések (e.g. send `Mobile/notebook/kits/kutya.json` with a changed id through Átadás) →
    "Betöltve: …", it shows as "saját", and Saját kit törlése removes it.
15. Close the app from recents and open again: everything is there.
