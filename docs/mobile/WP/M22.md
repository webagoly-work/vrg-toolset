# M22 · Claude (`claude`): the Claude app and the PC's Remote Control sessions

**Goal.** The user's words (2026-11-12): "plugin for claude app sign in - with a Remote Control session opened on a
PC, it should be even more like the full Desktop capable". VRG Mobile never signs in to Claude itself: the official
Claude app does. With a paired PC, the relay lists the Remote Control sessions it started and can start one. Map:
`../PARITY.md` (window kind `chat`, frame part "Claude sign-in"). Built 2026-11-12, **BETA**.

## Build

- **No Claude sign-in inside VRG Mobile, ever.** The Claude window shows the one thing the phone can know (whether the
  official Claude app, `com.anthropic.claude`, is installed; the manifest names it under `<queries>` so Android 11+
  lets the phone see it). ✶ Megnyitás starts the app; without it, claude.ai opens in the browser and Telepítés › goes
  to the Play Store. VRG Mobile never asks for or stores a Claude password or token.
- **The relay** (`Planner/projects/varler-planner/tools/relay-claude.js`, wired in `phone-relay-server.js`): three
  messages, trusted (paired) phones only, and **off unless the relay runs with `--claude`** (`RELAY_CLAUDE=1`;
  `Mobile\mobile.cmd relay` now passes it):
  - `claude.list` → the folders, the accounts, the sessions this relay started (running or not, with their links);
  - `claude.start {folder, account}` → `claude remote-control --name "VRG <folder> <HH:MM>"` in that folder, detached,
    no window, its output to `%TEMP%\VRG\claude\<id>.log`; the relay waits up to 20 s for the session link the CLI
    prints (`https://claude.ai/…`, ANSI stripped) and passes it back;
  - `claude.stop {id}` → only a session this relay started, by its pid (the process tree).
- **The folders are START's own**: START → C (Claude Code)'s items, narrowed by `Mobile/catalogue/claude.json`
  (1 = the repo root, 2 = Planner, 3 = Inventory; not B, Bernard, which has its own arguments). **The accounts are the
  Desktop's profiles**: A = `claude-a`, B = `claude-b` with its own `CLAUDE_CONFIG_DIR` (`Dashboard/config/profiles.json`).
  **The exe is START's `{claude}`**, resolved from `claude.cmd` to the `claude.exe` it calls, so no `cmd.exe` and no
  shell is ever in the way.
- **The rule, as Indítópult's**: the phone sends a folder key, an account letter and a session id, each checked against
  lists built on the PC. The session's name is made by the relay (ASCII). No string from the phone reaches a command
  line, a path or a URL; a link the relay passes back is accepted by the phone only if it is `https://claude.ai/…`.
- **Sessions survive a relay restart**: kept in `%LOCALAPPDATA%\VRG\relay-claude.json` (next to the paired phones),
  checked by pid; a stopped one is listed for a day. At most 6 at once.
- **The phone** (`feature-claude`, `kit-core/Claude.kt`): the app card, then the PC card (relay, pairing, the reason
  when `--claude` is off), the sessions (● running, folder, account, time; ✶ Megnyitás a Claude-ban hands the link to
  the Claude app, else the browser; ■ Leállítás), and Új munkamenet (fiók A / B, ▶ Indítás per folder). The list
  refreshes every 8 s while open, so a link that came late appears.
- **In Lapok**: the Desktop's `chat` pane is this feature (`pane:chat` → `feat:claude`).

**One difference from the brief:** the brief speaks of sessions "the PC's VRG Desktop started", but the Desktop does not
start Remote Control sessions today (`claudeterm.js` opens Claude Code in a terminal pane). The relay starts and keeps
them itself; the Desktop listing the same sessions is a Later item.

## Telefonon ellenőrizni

0. On the PC, once, by hand: `claude remote-control` in the repo in a terminal, so any first-run question (enabling
   Remote Control for the account) is answered there. Stop it. Then `Mobile\mobile.cmd relay` (now with `--claude`).
1. Claude tile → „CLAUDE ALKALMAZÁS” says Telepítve (or offers claude.ai ↗ and Telepítés ›); ✶ Megnyitás starts the
   Claude app, signed in there.
2. The PC card shows the PC and three folders (A repo gyökere, Planner projekt, Inventory projekt), Fiók: A / B.
3. ▶ Indítás on „A repo gyökere” → „indul…”, then a session row with ● and ✶ Megnyitás a Claude-ban (within ~20 s;
   if the link comes later, the row fills itself in).
4. ✶ Megnyitás a Claude-ban → the Claude app opens on that session; a prompt there runs on the PC, in the repo.
5. On the PC: no new window appeared; `%TEMP%\VRG\claude\c1.log` has the CLI's output.
6. Restart the relay → the session is still listed (● if it still runs); ■ Leállítás stops it (gone from Task Manager).
7. Fiók B → a session under account B (its own sign-in on the PC).
8. A relay started without `--claude` (START G): the card says how to turn it on; an unpaired phone is asked to pair.
