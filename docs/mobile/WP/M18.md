# M18 · Archívum (`archive`): the Artifact Archive on the phone

**Goal.** The Founder's words (2026-11-11): an "Artifact Archive" feature in VRG Desktop **and VRG Mobile**: one
container listing every one-shot interactive HTML page Claude made for them (published claude.ai artifacts and local
one-off pages), each with brief context — when it was made, what development was going on then, why it was wanted —
VRG items first. The Desktop part is VRG Desktop WP-47 (decision DESKU-Q24 in `docs/desktop/DECISIONS.md`): the repo
folder `Archive/` with `index.json` → `index.js`, the saved copies `files/<id>.html`, the CLI `Archive/archive.js`
and the viewer `Archive/vrg-archive.html`. This WP puts that same folder on the phone. Decision D-13 (below and in
`../DECISIONS.md`) records how it reaches the phone.

## Build (D-13)

- **One source, read from main.** The phone reads `Archive/` straight from `main` through the contents API, like
  Haladás reads `Mobile/catalogue/tools.json`: no publish step, no orphan branch, no second copy of the data. A new
  entry added on the PC (`node Archive/archive.js add …`) reaches the phone with the next push to `main` and ⟳.
- **Phone, rules** (`kit-core/Archive.kt`, tested in `ArchiveTest`):
  - `ArchivePages`: the paths, `keeps()` (the viewer, `index.js`, `files/<safe name>.html` — never `archive.js`,
    `index.json` or anything else in the folder), `route()` for the WebView, `mime()`.
  - `ArchiveManifest.fromListings`: the two listings (`Archive/`, `Archive/files/`) → path → git blob sha + size.
  - `ArchiveSync.decide`: Fresh / Download(fetch, drop) / Offline / Missing. Only files whose sha or size differ are
    fetched, the viewer and `index.js` first; a file gone from main is deleted on the phone.
  - `ArchiveWeb`: the artifact CDNs a saved page may load from, and `BACK_JS` (below).
- **Phone, module** `feature-archive` (`ArchiveFeature`): one row (‹, ARCHÍVUM, "N mentett oldal · x MB", ⟳), the
  status line, the WebView below. ⟳ lists (ETag-cached, cheap) and downloads changed files through the contents API
  (`Accept: application/vnd.github.raw`), each to `.part`, checked against the listed size, renamed. The manifest is
  written after every run, so a cut download keeps its finished files and the next ⟳ fetches only the rest.
  Copies in `filesDir/archive/`; offline opens the last copy with "· offline".
- **The viewer is the PC's page, unchanged in behaviour.** It already lays itself out for a phone under 760 px
  (list → entry → full-screen viewer, hash routes `#<id>` and `#<id>/open`). The one phone fix went into the page
  itself, not a fork: a `(max-width: 760px), (pointer: coarse)` block makes every control at least 44 px tall
  (MIND / VRG / EGYÉB, the group select, search, cards ≥ 52 px, ← Lista, ▶ Megnyitás, claude.ai ↗, Archivált fájl,
  the viewer's ← Vissza and claude.ai ↗).
- **The WebView** is M17's: JavaScript and DOM storage on, file / content access off, served from
  `https://appassets.androidplatform.net/archive/<file>`; only `ArchivePages.route()` files are answered, everything
  else an empty 403. Exception, new here: a **GET over https to an artifact CDN** (`fonts.googleapis.com`,
  `fonts.gstatic.com`, `cdnjs.cloudflare.com`, `cdn.jsdelivr.net`, `unpkg.com`) goes to the network, because the
  saved pages are published artifacts that load fonts (and one a library) from there. A tap on any outside link
  (claude.ai ↗, a datasheet link inside a saved page) opens the phone's browser, never inside the app.
- **Back.** The viewer keeps its place with `history.replaceState`, so the WebView's own history cannot step back
  through it. Back runs `ArchiveWeb.BACK_JS` in the page, using only `window.VRGArchive.state()` / `select()`:
  the open saved page closes (→ the entry), then the entry goes back to the list, then the app leaves the
  archive. A saved file opened in the main frame ("Archivált fájl") steps back through WebView history first.
- **Links:** `vrg://archive/<id>` opens that entry, `vrg://archive/<id>/open` its saved page too.
- **Catalogue:** `Catalogue.ARCHIVE` (🗂, Munka, BETA, needs Internet + GitHub), after Rétegverem.
- **Haladás (M4):** `tools/build-mobile-tools.js` lists `Archívum` → `Archive/`, so pushes to the archive show under
  its own name; `Mobile/catalogue/tools.json` regenerated (it also picked up VRG UI Kit galéria and VRG Térkép, which
  the generated file had been missing).

## Telefonon ellenőrizni

1. Kezdőlap → Munka → **Archívum**: GitHub belépéssel ⟳ letölti (a sorban „N mentett oldal · x MB”).
2. A lista: elöl a VRG, aztán az egyéb; MIND / VRG / EGYÉB, csoport és keresés kényelmesen nyomható.
3. Koppintás egy sorra → a részletek; **▶ Megnyitás** → a mentett oldal teljes képernyőn; a betűtípusok rendben.
4. **Vissza gomb**: mentett oldal → részletek → lista → kezdőlap.
5. **claude.ai ↗** (a részleteknél és a nézőben) a telefon böngészőjében nyílik, nem az appban.
6. **Archivált fájl** → a mentett fájl; Vissza visszahoz az Archívumba.
7. Repülő mód: az Archívum a legutóbbi változatot mutatja „· offline” jelzéssel, a mentett oldalak megnyílnak.
8. A PC-n `node Archive/archive.js add …` + push a main-re → a telefonon ⟳ csak az új fájlt tölti le.
