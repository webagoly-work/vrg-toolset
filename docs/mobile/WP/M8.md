# M8 · Localhost (`ports`): the PC's local servers on the phone and on the desktop

**Goal.** The toolset starts many local servers: MindMap 8124, Inventory 8123, Kódváros live 8797,
Board Console 8790, CYD settings 8788 and more. The phone lists the ones running now. A tap opens one
**on the phone** or **on the PC in a separate app window**. Answer D-10 first.

## Build

- **Relay** (paired phones only, M2):
  - `ports.list` → listening TCP ports on 127.0.0.1 / 0.0.0.0, read with `Get-NetTCPConnection -State Listen`
    on Windows and `ss -ltnp` elsewhere. Each port comes with its process name, the HTTP `<title>` from a 1-second
    probe, and a known name from `Mobile/catalogue/ports.json` (port → tool, kept beside tools.json).
  - `ports.open {port, path, where:'desktop'}` → opens `http://localhost:<port><path>` in a separate window.
    It uses the portable Chrome's `--app=` (`Full/tools/chrome`, else the system browser's new window).
    **Only localhost URLs**: the relay builds the URL itself from the port number, never from a string.
  - If D-10 includes the proxy: `/p/<port>/…` reverse-proxies to localhost for trusted phones, rewriting
    `Location` headers. Off unless the relay is started with `--ports`.
- `feature-ports`: a list with name, port, process, and a status dot. Buttons "📱 Itt" (WebView, or the browser
  through the proxy) and "🖥 A PC-n".

## Tests (cloud)

path rewrite, and an untrusted phone being refused.
