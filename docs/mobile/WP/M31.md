# M31 · Variánsok: a Variant Sketcher for one kind of job, made by an agent

**Goal.** The user: a prepared agent brief (a protocol) for making a **variant version of the Sketcher** — and of its
note, camera and questionnaire modules — reshaped for a temporary job: the user starts it, the agent asks for one to
three sentences (with keyword tags to tick), plans a first version in the background, asks the crucial questions and
for photos, then fine-tunes the tools (e.g. the drawing tools, so the job's typical shape is easy to sketch), as if
they had been made for this kind of work. **Variants appear under the options of the original, with a toggle in the
upper corner switching between the original and the variant.** BETA, 2026-11-18. D-33.

## Build

- **The variant** is data (`Sketcher/variants/<id>.json`): the rail's order, plugins on/off, the point wheel's first
  ring and named **point presets** (type + tags: *Törölközőszárító*, *Töltő (wallbox)*…), the room wheel's first ring,
  **room templates** for the new **Sablon** tool (drag the shape to size: *Kádfülkés fürdő*, *Garázs + beálló*), tags,
  preset scope, extra chips / questions / shot-list items / purposes, one hint line per tool. Two reference variants:
  *Fürdőszoba felújítás*, *E-autó töltő telepítés*.
- **On the phone**: ⚙ → **Variánsok**: *Eredeti* or a variant (it brings its tags, preset scope and plugins); the
  **toggle in the top corner** (its symbol in its colour / grey ◐) switches back and forth at any moment;
  **⟳ Frissítés a main ágról** fetches new variants (GitHub, the M3 sign-in); the bundled ones come with each release.
- **Új variáns kérése**: one to three sentences (typed or dictated), the toggles that describe the job, up to five
  photos → `variant-request-<time>.json` (kind `vrg-sketcher-variant-request`: the premise, the toggles, the counts of
  what is drawn — **never the survey's name, the address or the notes**) shared with the photos (Átadás → PC-re), and
  the prompt `GO VARIANT — <file>` + the premise copied to the clipboard.
- **The agent side**: codephrase **GO VARIANT** (`GO-VARIANT.md`) → `Sketcher/variants/PROTOCOL.md`: read, plan without
  asking, ask the crucial questions and for photos, write, `node Sketcher/tools/variant-check.js`, test, report
  *original → variant*, commit on main.
- **The Desktop page** lists the variants, has the same toggle, and copies a GO VARIANT starter prompt.

## Tests

`variant-check.js` (shape, ids, file name, merge); FieldKitTest parses every variant and checks the merge;
VariantToolsTest (the default wheels unchanged, a variant's order, a template stretched over the drag, choosing a
variant twice changes nothing more); the request has no client data (FieldKitTest).

## Telefonon ellenőrizni

1. ⚙ → Variánsok → *Fürdőszoba felújítás*: a sáv Szoba, Sablon, Méret, Pont, Fotópont…; a sarokban 🛁.
2. Sablon → *Kádfülkés fürdő* → húzd: a fürdő alakja kész. Pont: *Tükörvilágítás*, *Aljzat IP44* előre.
3. A szoba kereke: Fürdő, WC, Mosókonyha elöl. A Kérdésekben a fürdő saját kérdései (zóna, FI).
4. A sarok ◐-jére koppintva az eredeti; vissza.
5. ⚙ → ＋ Új variáns kérése: két mondat, kulcsszavak, egy fotó → Küldés → PC-re; a vágólapon a GO VARIANT szöveg.
   A PC-n egy Claude Code munkamenetben `GO VARIANT` + a fájl: az ügynök kérdez, megírja, commitolja.
6. ⟳ Frissítés a main ágról: az új variáns megjelenik.
