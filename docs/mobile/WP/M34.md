# M34 · Ikon: the Varler mark as the app icon, in the user's palette, and behind the home

**Goal.** The Founder, 2026-11-18: the app's logo was still Légegér's (a pointer over two swells); make it the Varler
logo *without the letters*, its colour following the palette chosen in the app, and show the logo faintly behind the
main dashboard. Built in a cloud session, **BETA**.

## As built

- **The mark.** `shared/varler-logo/lockups/lockups.json` → `mark`: the original Varler mark (bulb, leaves, E27 base),
  the same path every lockup draws under its text. No wordmark. (The animated logo v1 and its ring stay GO LOGO's job.)
- **One icon per palette.** `Mobile/catalogue/icon-gen.js` reads the mark and every palette's `abyss` / `glow` from
  `kit/theme/Melyviz.kt` and `kit/theme/KitTokens.kt`, and writes an adaptive icon per palette (background = abyss,
  the mark in glow, standing 56 of 108 units, inside the 66-unit safe zone), a white monochrome layer for Android 13+
  themed icons, the plain mark for the app (`kit` `vk_varler_mark`), and one launcher `activity-alias` per palette in
  the app manifest (between the `launcher-aliases` markers; Mélyvíz enabled). `--check` runs in `mobile.cmd test` and
  in Actions; `kit-core` `LauncherIconTest` checks every palette has its alias and icon and only the default is on.
- **The switch.** An app cannot repaint its launcher icon, so `app/LauncherIcon.kt` enables the alias of the current
  palette and disables the others (target first, so there is always an entry), with `DONT_KILL_APP`. It runs in
  `onStop`, when the app leaves the screen, so trying palettes does not make the icon blink.
- **The home's watermark.** `kit/ui/Watermark.kt` `VarlerWatermark()`: the mark at 62 % of the screen, centred, in the
  palette's glow at 6 % (7 % on the light palettes), behind both homes (Asztal and Kompakt). Decorative; TalkBack skips it.
- `ShellActivity` is no longer a launcher entry itself; the aliases are.

## Known effects

- **After this update the old home-screen icon may vanish** (it pointed at ShellActivity's launcher entry, which is
  gone): add it again from the app drawer once. The same can happen on some launchers each time the palette changes
  (the icon then belongs to another alias); MIUI and One UI usually swap it in place after a few seconds.
- The app drawer and Settings → Apps show the enabled alias's icon; the notification icon is unchanged.

## Telefonon ellenőrizni

1. After installing: the drawer shows the Varler bulb on deep blue (Mélyvíz); the old Légegér icon is gone. Re-add
   it to the home screen if it disappeared.
2. Beállítások → Megjelenés → Korallzátony, leave the app (Home): within a few seconds the icon is coral on dark red.
   Try a light palette (Sekély víz) too.
3. Android 13+ with themed icons on: the icon follows the system colours (the monochrome layer).
4. The home (Asztal and Kompakt): the bulb shows faintly in the middle, in the palette's colour, and never covers a
   tile or a sheet. Lying down too.
5. Share → "PC-re" and the deep links (`vrg://…`) still open the app.
