# M37 · RCO: the long-press menu across the app

**Goal.** The Founder, 2026-11-19, with a screenshot of the Asztal dock: "RCO to close/delete from that bar. Pivoting
from there, search for genuine RCO opportunities to add throughout the app." RCO is the toolset's right-click menu
(Kódváros, the Kapu); on the phone it is a long press. Built in a cloud session, **BETA**. Decision D-45.

## The shared part

`kit/ui/Rco.kt`: `Modifier.rco(onClick, onLong)` keeps the tap as it was and makes the long press buzz once and open
the menu (TalkBack offers it as "további műveletek"); `RcoMenu` is a Mélyvíz dropdown anchored to the item, its title
the item's name, removing lines in coral. Every menu below uses it, so they look and behave alike.

## Where it is (tap unchanged everywhere)

| Where | Long press offers |
|---|---|
| Asztal dock, an open window | Megnyitás · Bezárás · Többi bezárása · Mind bezárása (the last two with 2+ windows). Closing takes the window off the bar; a feature's background work is not stopped (VrgFeature has no stop hook). |
| Home icons (Asztal) and tiles (Kompakt) | Megnyitás · Megnyitás lapon (Asztal, built features: the active sheet's free cell, else a new sheet named after the feature) · *group* összecsukása |
| Értesítések, an event | Olvasottnak jelöl (unread only) · Link másolása · Megosztás (when it has a link) · Csak *kind* |
| PC ablakok, a file | Átadásra (without reading it first: big or binary files) · Megnézés · Név másolása; a folder: Megnyitás · Név másolása |
| Alkalmazások, an app | Megnyitás · Frissítés / Letöltés (one app, without opening it) |
| Haladás, a commit / a PR | Megnyitás a GitHubon · SHA másolása (commit) · Link másolása · Megosztás |
| Claude, a session | Megnyitás a Claude-ban · Link másolása · Megosztás · Leállítás; a tap on the row now opens the session too |
| Légegér, a screenshot thumbnail | Megosztás · Mentés a Galériába · Törlés, without selecting it first |

## Looked at and left alone

- **Indítópult tiles**: the long press already opens the tile's detail panel; replacing it with a menu is the
  Founder's call (the menu would hold ▶ A PC-n, 📱 a telefonon, Napló, ■ Leállítás).
- **Lapok** (window cards, free cells, tabs), **Csipogó** pad and message keys, **Képernyő** surfaces: the long press
  already means drag, resize, the picker, the sheet menu, a long message or SOS, or touch.
- **Localhost** rows: both ways to open are inline chips; the only addition would be copying a `localhost` address,
  useless on the phone (the proxied URL carries the relay token and must not be copied).
- WebViews (Archívum, Rétegverem, Kódváros, an app), single buttons (quick row, the Sketcher card, chips), rows whose
  only action is already inline (Makrók, Hálózat addresses, settings lists).
- Lower value, kept as candidates: Gyorsjegyzet outbox (edit / drop an unsent note; needs care with a running
  flush), Átadás board entries, Csipogó peers and chat bubbles, Beállítások paired PCs, Eszközök list rows.
- `feature-sketch`: another session owns it.

## Tests

No logic moved into kit-core (the menus call what each feature already had), so the core suites are unchanged; the
Actions build is the compile check. The menus are checked on the phone.

## Telefonon ellenőrizni

1. Asztal dock: open three features, back to the Asztal; long press a window: one buzz, the menu with its title.
   Bezárás removes it; Többi bezárása leaves one; Mind bezárása empties the bar ("nincs nyitott ablak").
2. Home icon (Asztal): Megnyitás lapon → a sheet with that feature (a new one named after it when on the Munkapad);
   again with a free cell on that sheet → it joins the same sheet. *Group* összecsukása folds the group.
3. Kompakt tile: the menu has no Megnyitás lapon; folding works.
4. Értesítések: an unread event → Olvasottnak jelöl turns its dot grey without leaving the list; Link másolása pastes
   the github.com link; Csak *kind* sets the filter chip.
5. PC ablakok: long press a large file → Átadásra → the note "A táblán: …" without reading the file.
6. Alkalmazások: long press a downloaded app → Frissítés runs its ring without opening it.
7. Haladás: SHA másolása pastes the full SHA; Megosztás opens the share sheet.
8. Claude: a running session → Link másolása; a tap on the row opens it in the Claude app.
9. Légegér → screenshots: long press a thumbnail that is not selected → Törlés removes it and the selected one stays.
10. TalkBack: an item reads its name and offers "további műveletek" as the long-press action.
11. A normal tap on every item above still does exactly what it did before.
