# VRG Kapu — UI specification

*UI text is Hungarian; code identifiers English (toolset rule). Node descriptions follow HUB-Q09
(A: Hungarian, English below in italics). Colours only from the VRG `THEMES` table in
`Modder/vrg-buildtree.html` (four themes) — a new colour is a theme var, never a literal.*

## 1. Screen

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ VRG Kapu   [🔎 Keresés… Ctrl+K]   Nézet:(Jelenlegi|Bővített)  [⟳ Frissítés]     │  top bar
│            [Belépések ●●○] [📝 Munkanapló] [⌨ Terminál] [✳ Claude Code] [☰]   │
├───────────────────────────────────────────────────────────────────────────────┤
│ Ki min dolgozik?  Witoo: Planner — Födém pen (ma) · Kolléga: Inventory (tegnap) │  status strip
│ ★ Kedvencek: Planner · Kalkulátor · CLA mappa                                  │
├────┬──────────────────────────────────────────────────────────────────────────┤
│ L1 │                                                                          │
│ L2 │                 THE BOARD (SVG, pan + zoom)                              │
│ L3 │                                                                          │
│ L4 │                                                                          │
│ L5 │                                                                          │
│ L6 │                                                                          │
└────┴──────────────────────────────────────────────────────────────────────────┘
  layer rail: click = show/hide that layer; the dot shows locked / open
```

- **Pan**: middle-drag or Space+drag; **zoom**: wheel (around the cursor), `+`/`−`, `0` = fit all.
  (Same mouse model as MindMap: left-drag on empty canvas = nothing in v1; middle = pan.)
- **Department header** click = collapse/expand; double-click = **Fókusz** (that department only,
  full width; `Esc` back).
- At zoom < 0.5 the description lines hide (titles only); at < 0.3 only department headers.

## 3. Node card

```
┌──────────────────────────────┐
│ ▣ Varler Planner          🔓 │   icon by kind · title · lock state
│ ● használatban  ⚑ Witoo-ig 10/25 │ status · claim badge (if any)
└──────────────────────────────┘
  A fő tervezőprogram: alaprajz,      ← description (d), always visible
  eszközök, körök, vezetékezés…
  *The main design tool: plans…*      ← dEn, italic, only if HUB-Q09 = A
```

Kind icons (text glyphs, no icon font needed): program ▣ · third-party ⧉ · folder ☁ · local folder 📁 ·
agent doc 🤖 · GO brief ▶ · git ⎇ · roadmap ● · custom ★ · empty slot ○.
Status words: `live` "használatban" · `dev` "fejlesztés alatt" · `idea` "tervezett" · `v2` "jövőkép".
Lock: 🔓 open · 🔒 needs sign-in (tooltip names which) · ⛔ not on the allowed list.

**Click** = the node's main action (§4). **Right-click / long-press** = the RCO menu (§5).
**Hover** = after 400 ms a tooltip with the short text and where the link goes.

## 4. Main action per node kind

| Kind | Click does | Fallback without companion |
|---|---|---|
| program (repo path) | companion `open-tool` (same browser + path as START.cmd) | show the `file:///` link + "Másolás" |
| program (url) | open URL in a new tab | — |
| folder (OneDrive url) | new tab | — ; empty url → "Még nincs megosztási link — Szerkesztés" |
| local folder | companion `open-folder` | copy the path |
| agent doc / repo file | `https://github.com/{o}/{r}/blob/{branch}/{path}` new tab | — |
| GO brief | copies "`<GO phrase>` — olvasd el a `<file>`-t és csináld, amit ír." + opens Claude Code chooser | copy only |
| git | `…/tree/{branch}/{path}` new tab | — |
| roadmap entry | commit → `…/commit/{sha}`; seed entry → the info drawer | — |
| custom (L5) | its URL in a new tab | — |

## 6. Panels

**Info drawer** (right side, 380 px): title, kind, status, *Rövid* / *Részletes* tabs (markdown
rendered, HU then EN), link list, last 8 commits (L4), open decision count, claim, "Szerkesztés".

**Belépések** (modal):
```
GitHub        ● ellenőrizve: webagoly-work · hozzáférés: írás     [Bejelentkezés (új ablak)] [Token…]
OneDrive      ○ nincs ellenőrizve  ☐ Be vagyok jelentkezve         [Bejelentkezés (új ablak)]
Claude        – saját fiók                                        [Claude Code megnyitása]
Engedélyezett lista  ✓ aláírás rendben · 2 fő · te: tag             (owner sees: "Tulajdonos")
Kapu segéd    ● fut (localhost:8795)                               [Hogyan indítom?]
```
**Token varázsló** (5 steps, each one sentence + where to click on github.com): Settings → Developer
settings → Fine-grained tokens → Generate → Repository access: *Only select* `vrg-toolset` →
Permissions: Contents *Read and write*, Metadata *Read* → Expiry 90 days → copy → paste here.
Shows: "A token csak ebben a böngészőben marad. Ne küldd el senkinek, ne tedd fájlba."

**Munkanapló** (modal form → markdown):
```
Ki: [webagoly-work]  Dátum: [2026-10-21]  Programok: [☑ Planner ☐ Inventory …]
Mit csináltam:        [……]
Félkész / nyitott:    [……]
Következő lépés:      [……]
Kérdések:             [……]
Linkek:               [……]
[Letöltés .md]  [Mentés a célmappába]  [Feltöltés GitHubra]  [OneDrive mappa]  [Importálás…]
```
Template (exact):
```markdown
---
type: vrg-munkanaplo/1

by: webagoly-work
programs: [planner]
---
# Munkanapló — 2026-10-21 — webagoly-work

## Mit csináltam
…
## Félkész / nyitott
…
## Következő lépés
…
## Kérdések
…
## Linkek
…
```

**Szerkesztő** (modal): fields of the node (t, d, dEn, long, links, status, department), "Új elem",
"Törlés" (soft: `hidden:true`, restorable), "Mentés GitHubra" + "Exportálás JSON". Owner-only
fields are not shown to members (access list editing is not in the page at all — only `hub-sign.js`).

**Első lépések** tour (6 steps, dim the rest, highlight one thing):
1. "Ez a térkép a cég összes munkája. Fent a részlegek, alattuk a programok."
2. "Minden elem alatt egy mondat elmondja, mi az. Jobb klikk: rövid és részletes leírás."
3. "A rétegek: programok, közös mappák, AI dokumentumok, kód. Bal oldalt ki-be kapcsolhatod őket."
4. "Belépések: a GitHub fiókoddal nyílnak ki a programok. Kattints ide."
5. "Munkanapló: a nap végén írd le, mit csináltál — a másik így látja."
6. "Elakadtál? A ☰ menüben van a Szótár és ez a bemutató."

**Szótár**: 25 entries, one line each, e.g. "**Commit** — egy mentés a repóban: ki, mikor, mit változtatott."
