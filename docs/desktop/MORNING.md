## Independent check (theresa)

A read-only reviewer tried to prove U4–U8 wrong against PROMPT.md and CONTRACT.md. Found and fixed in U9:

- **Bug — START D was broken by U8.** The `.cmd` was written through a shell string that turned `\b`, `\v`, `\t` into control
  characters, so neither the exe nor electron.exe was ever found. Rewritten; the test now *runs* the `.cmd` with cmd.exe (a copy under
  %TEMP%, `start` → `echo`) for all three cases and rejects control characters. The old test only matched substrings.
- **Risk — `vrg-app://` name tricks.** `secrets.bin.`, a trailing space, `x::$DATA` streams, `:port` / `user@` hosts (another origin)
  were not refused; nothing secret was reachable today, but they are refused now. With `realpath` a junction or symlink inside a served
  folder that leads elsewhere is refused too.
- **Risk — double Tab.** Typing inside an iframe read as "not editable", and a slow renderer could hand main a stale pair. A focused
  iframe is now followed into its document (cross-origin counts as taking text), and the recorder's notes carry times: only a fresh pair
  within the interval counts, otherwise it reads again, then falls back to the probe.
- **Nits — package.js.** The marker is written first (`building: true`), so a stopped build is still ours and `--check` names it;
  out-as-a-file and a running exe give clean errors.

Left as they are, and stated: Esc inside an in-shell app stays with the app (DESKU-Q15; PROMPT U7 said Esc returns); the gate is tested
as a state machine for both flag values, but its screen with the flag on is never rendered by a test; a plain double Tab on any
focusable control toggles, as asked (a keyboard user moving fast through tiles may hit it).
