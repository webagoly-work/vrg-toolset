# P12 prerequisite · Windows 10 21H2 → 22H2 (CITY-D19 A: the user does it, from these steps)

Written 2026-10-27 (primary account, before KV-25). Claude changes nothing here: every step below is yours.

## Why

KV-25/26 (the Electron overlay) need 22H2: Microsoft's promise to keep Edge and WebView2 updated until at least
October 2028 applies to 22H2 only, and .NET 10 / Electron are tested there (report §1.5, §1.8). The step itself is small:
21H2 and 22H2 share the same system files, and 22H2 is switched on by a ~180 KB **enablement package (KB5015684)** with
one restart ([Microsoft](https://support.microsoft.com/en-us/topic/kb5015684-featured-update-to-windows-10-version-22h2-by-using-an-enablement-package-09d43632-f438-47b5-985e-d6fd704eee61)).

## What this PC looks like now (read 2026-10-27, nothing changed)

| Last update installed | KB5016616, **14 Aug 2022** — no update in four years |
| Prerequisite (the 26 Jul 2022 cumulative update, build 19044.1865 or later) | **met** (1889 ≥ 1865) |
| Windows Update service `wuauserv` | **Disabled** |
| Its repair service `WaaSMedicSvc` | **Disabled** |
| Policy `HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate` | `DisableWindowsUpdateAccess = 1`, `DisableOSUpgrade = 1` |
| Free space on C: | 535 GB |

So Windows Update was switched off on purpose (in 2022, by you or a tool). The 22H2 package comes **only** through
Windows Update (Microsoft's catalog does not offer it), so it has to be switched on — at least for this step.

**Know before you start:** Microsoft's free security updates for Windows 10 (consumer ESU) ended on **13 October 2026**.
Turning Windows Update on now still brings the four years of fixes that were published up to then (a big gain on a PC
that has had none since 2022), but no new ones will follow. That is a separate decision from 22H2, but this step makes it
visible.

## Steps

**1. A restore point and a record of today's settings** — Start → type *PowerShell* → right-click **Windows PowerShell**
→ **Run as administrator**, then paste (one block):

```powershell
Checkpoint-Computer -Description 'Before 22H2 (Kodvaros P12)' -RestorePointType MODIFY_SETTINGS
reg export "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" "$env:USERPROFILE\Desktop\wu-policy-before.reg" /y
Get-Service wuauserv, WaaSMedicSvc, UsoSvc | Select-Object Name, StartType, Status | Out-File "$env:USERPROFILE\Desktop\wu-services-before.txt"
```

(If *Checkpoint-Computer* says System Protection is off, that is fine — the two files on the desktop are the record.)

**2. Switch Windows Update on, but keep it on Windows 10 22H2** (no offer of Windows 11, no driver swaps — your GTX 1050 Ti
driver stays). In the same admin PowerShell:

```powershell
$k = 'HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate'
Remove-ItemProperty -Path $k -Name DisableWindowsUpdateAccess, DisableOSUpgrade -ErrorAction SilentlyContinue
New-ItemProperty -Path $k -Name TargetReleaseVersion -PropertyType DWord -Value 1 -Force | Out-Null
New-ItemProperty -Path $k -Name ProductVersion -PropertyType String -Value 'Windows 10' -Force | Out-Null
New-ItemProperty -Path $k -Name TargetReleaseVersionInfo -PropertyType String -Value '22H2' -Force | Out-Null
New-ItemProperty -Path $k -Name ExcludeWUDriversInQualityUpdate -PropertyType DWord -Value 1 -Force | Out-Null
Set-Service wuauserv -StartupType Manual
Start-Service wuauserv
Get-Service wuauserv
```

The last line must say **Running**. (`WaaSMedicSvc` is a protected service; leave it as it is — Windows Update works
without it.)

**3. Install 22H2** — Settings → **Update & Security** → **Windows Update** → **Check for updates**. Look for
*Feature update to Windows 10, version 22H2* → **Download and install** (it may also start by itself, because of the
22H2 target in step 2). Let the other updates it finds install too. **Restart** when it asks.

**4. Check** — Start → type `winver` → it must say **Version 22H2 (OS Build 19045.…)**. Then Windows Update → *Check for
updates* again, until it says you are up to date (the cumulative updates since 2022 may need two or three rounds and
restarts).

**5. Tell Claude "22H2 kész"** — KV-25 (the Electron overlay) starts from there.

## Going back

- **To 21H2:** Settings → Update & Security → Windows Update → *View update history* → *Uninstall updates* → select
  *Feature Update to Windows 10 22H2 via Enablement Package (KB5015684)* → Uninstall → restart. The security fixes stay.
- **To Windows Update off again** (your 2022 state): double-click `wu-policy-before.reg` on the desktop (it restores the
  two Disable… values; the four values from step 2 stay unless you delete them in regedit), then in an admin PowerShell:
  `Stop-Service wuauserv; Set-Service wuauserv -StartupType Disabled`. Since 13 Oct 2026 no new fixes arrive anyway, so
  turning it off after step 4 loses little; turning it off before step 4 keeps the four-year gap.
- **Everything:** the restore point from step 1 (Start → *Create a restore point* → *System Restore*).
