1 · Definition

What it is

The VRG Stack is one graph of the whole VRG work, cut into layers. Each layer is one way of seeing the same body of work: what exists, why, who did it, what changed, where it lives, how it is reached, whether it works and what is wrong. Vertical links join the same real thing across layers.

The idea that carries it is the String (Füzér). Pick anything on any layer and follow its vertical links. The set of layers it reaches is its reach mask, and the mask is the thing's development state. Nobody types the state in; it falls out of the data.

Source
Anything the work already keeps: git, the decisions files, START's registry, the job register, the recorded sessions, the UI kit. Sources are read, never written, except through the gateway.
Layer
A filter of the work (ideas, decisions, commits) or a shadow of it (the codec, the words). One letter, one adapter and one page per layer.
Node and edge
A thing on one layer (Q:VIS-Q5, R:5ee8b1e), and a typed relation with a verb. A horizontal edge stays inside a layer; a vertical edge crosses layers.
Pillar · E
One real thing across every layer (Planner, Kapu, VRG Mobile), kept by hand, owned by a Council Head.
Signal · J
Every warning, as a node standing on what it is about. A warning therefore has a string too: who owns it, what tested it, which decision governs it.
2 · Mechanism

How it works

sources→adapter per layer→join→record · runs→pillars · validate→analytics→signals→graph · events · index→page data · reports

Guarded build

A failing layer is carried forward from the last good build, so it never empties. Optional stages are skipped. Writes are atomic under one lock. out/ is disposable; data/ is append-only history.

Live twin · S5

A source map knows which layer each file feeds. A hand edit re-runs one adapter, the rest comes from the layer cache, and a test proves the result equals a full build. Open pages reload in about a second.

Page contract · S7

Every page declares what it can light up. Select something on one page and every other open page lights that thing's string in its own vocabulary. A lint test holds all pages to it.

Write gateway · S6

The one write path. It previews the exact diff, applies it only if the file is unchanged and its own parser reads the result, logs an event, and never commits.

Stack Viewer · S8–S10

WebGL planes filled with particles made from each layer's own text, about one particle per 16 bytes, with a time scrubber and a live diff glow. The phone gets byte classes only, never the text.

Asking it

CLI and MCP: hybrid search (BM25, heading chunks, optional bge-m3, fused by RRF), node cards, time-respecting paths. The MCP side is read-only and cannot start a build.

StepLayerReadsSignals it raises

Privacy is per layer and tested. Client jobs appear as codes only. People appear by role only. The asks' words never leave the PC, and the phone sees byte classes, never bytes.

4 · Value

Benefits

One truth, many faces

No page holds state, so no two pages can disagree.

State is measured

A hand-typed status is checked against the string's reach. A gap becomes a drift card.

Cheap for agents

One query replaces opening ten files, and the saving grows with the repo.

Warnings with context

A signal carries the string of the thing it is about.

Safe by construction

Read-only sources, disposable outputs, append-only history, one reviewed write path.

Fixed recipe

Eleven layers were added the same way. A twelfth costs about one session.

5 · Review

Strengths and weak points

The model is right-sized and the failure handling is mature. The risk is that the line went wide before it went deep.

Right-sized modelstrength

Layers, vertical edges and a reach mask are a small idea that pays for itself many times over. It needs no ontology, no graph database and no model.

Failure behaviour learnt from real breakagesstrength

Carried-forward layers, six health checks, doctor --fix, atomic writes, and tests with known answers, including incremental-equals-full and the privacy assertions.

Built against fixturesweak

No new layer has run on the PC's real jobs, boards, recordings or Visual Base. The signal heuristics were tuned on small data and will need another round.

Breadth before depthweak

21 layer slots and 24 pages. Some pages will be opened rarely. The event log can measure which.

The layer table is copied seven timesweak

Order and colours live in seven files. A missed copy is how the Konnektóm broke. The fix is one shared layer table.

Heavy phone pagesweak

The Viewer and Érintésnyom are about 3 MB each in the bundle. They need lazy planes and level-of-detail data.

Windows paths, one maintainerwatch

Hard-coded H: paths make cloud runs fragile, and 59 modules are a lot for one person to hold. Keep the recipe strict.

7 · Generality

Generic use with databases

The Stack assumes only three things: each source can be read into nodes and edges, things on different sources share keys, and someone can say which relations count as vertical. Any group of databases meets those three.

StackIn a database estate
Layera system or domain: CRM, ERP, tickets, billing, code host, HR, telemetry
Adapteran extract query or change stream that turns rows into nodes and keys into edges
Vertical edgea key shared across systems: a customer id in CRM and billing, an issue key in a commit
Pillara master-data entity: the golden customer, the product, the site
Stringcross-system lineage of one entity
Reach maskdata completeness: an order in ERP and billing but not in shipping is a stuck order
Classlifecycle stage computed from reach: lead → customer → paying → churned
Signala data-quality rule as a node: orphans, broken references, stale syncs
Gatewaya reviewed change set, applied through the owning system's own API

In SQL it is three tables and one recursive query:

CREATE TABLE layer (code CHAR(1) PRIMARY KEY, name TEXT, ord INT);
CREATE TABLE node  (id TEXT PRIMARY KEY, layer CHAR(1) REFERENCES layer, kind TEXT,
                    title TEXT, t DATE, state TEXT, props JSONB);
CREATE TABLE edge  (a TEXT REFERENCES node, b TEXT REFERENCES node, rel TEXT, w REAL DEFAULT 1,
                    vertical BOOLEAN GENERATED ALWAYS AS (left(a,1) <> left(b,1)) STORED);

-- the string of one seed: vertical edges, two hops, scores below 0.15 dropped
WITH RECURSIVE s(id, score, depth) AS (
  SELECT :seed, 1.0, 0
  UNION ALL
  SELECT CASE WHEN e.a = s.id THEN e.b ELSE e.a END, s.score * e.w, s.depth + 1
  FROM s JOIN edge e ON (e.a = s.id OR e.b = s.id) AND e.vertical
  WHERE s.depth < 2 AND s.score * e.w >= 0.15)
SELECT n.layer, n.id, max(s.score) FROM s JOIN node n USING (id)
GROUP BY n.layer, n.id ORDER BY n.layer;

Where it sits

Data catalogs and lineage standards (DataHub, OpenMetadata, OpenLineage) already map tables and jobs as a graph, and process mining follows an entity's path through time. What the Stack adds is the layered reading: an entity's coverage across layers taken as its lifecycle state, and drift as the gap between declared and measured state.

What a generic version still needs

Fuzzy identity resolution with the confidence as edge weight; a set-based join beyond about a million edges; access rules per layer kept as data; and an adapter kit, where each layer declares its nodes, edges, keys and vertical relations.

8 · Reach

Potential applications

The Data Vault

What you know about a person or project across every store you keep, and what lives in only one place, which is the backup risk. It works fully offline.

An electrician's business

Lead → survey → plan → quote → materials → job → invoice → warranty. A job that reached quote but not materials is stalled.

A software team

A feature with code and no test, an incident with no postmortem, a document no code refers to.

Compliance and audit

A rule with no control, or a control with no evidence. The string is the audit trail.

Client hand-over

A job's string, filtered to what the client may see.

Research labs

An idea that never reached an experiment, or a result with no code that produced it.
