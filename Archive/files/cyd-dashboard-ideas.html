Alert banners and LED

Any page can flash a banner over whatever is showing: FPS drop, lag spike, a download starting mid-match, a disk running out of room. The LED backs it up in colour.

Mute light everywhere

The RGB LED glows red while you're muted, on every page, in sync with Discord.

Automatic page switching

The screen follows what you're doing. Long-press to pin a page and stop switching. Rules are edited on the PC.

Alerts→Comms when someone talks→Match while playing→Session after a match→Dim when idle

Wireless later

USB today. Later: WiFi set up from your phone, the CYD finds the PC on its own, and firmware updates arrive over WiFi with no more cable flashing.

Feature details

How each pick grows

RL session tracker

  • Starts with the game, ends after a long break, then shows a summary card
  • Hot-streak badge, and a gentle "3 losses in a row, take five?"
  • Personal records: fastest goal, most saves, longest win streak
  • Teammate log: "played with Kaiser 5 times, 4 wins"

The game's Stats API doesn't report MMR, so that number comes from a tracker site.

Now playing (game)

  • Detects any game by its running program, not just Rocket League
  • Session timer per game and weekly playtime bars
  • Achievement pop-ups with rarity ("unlocked by 3.2% of players")
  • Cover art cached on the CYD so it appears instantly

Discord voice panel

  • Speaking ring around each person, plus join and leave notices
  • Volume slider per person
  • Mute and deafen by touch

Discord limits its voice API to approved apps. Step one is mute and deafen through Discord's own hotkeys from the Deck; the full "who's talking" view follows.

FPS & frame time

  • Frame-time graph with stutter spikes marked in red
  • Alert when FPS falls below a target you set, such as your monitor's refresh rate
  • Per-session summary: average FPS, 1% lows, stutter count
  • GPU temperature and load on the same page

PresentMon runs on the PC and may need admin rights.

Network

  • Lag spikes logged during matches and linked to results
  • "Steam update is using 80% of your bandwidth" warning mid-match
  • Ping to your game region and a clear "internet down" state

Disk space & health

  • Watches the games drive and warns before an update won't fit
  • Weekly health check that stays quiet unless something is wrong
  • Recording-drive space if you use instant replay or OBS

Macro pad

  • Button sets for Rocket League, Discord and the desktop, switched automatically
  • Clip button: save the last 30 seconds (NVIDIA instant replay or OBS)
  • "Game night" macro: opens the game and Discord, switches to the headset
  • Long-press for a second action

Mic-mute light

  • One mute state shared with Discord
  • Live mic level so you know you're heard
  • "You're talking while muted" warning
  • Red LED on every page while muted

Automatic page switching

  • Clear priority order, from alerts down to the idle screen
  • Long-press any page to pin it for a while
  • Rule editor on the PC: "when Rocket League runs, show Match"

Wireless later

  • First-time WiFi setup from a phone
  • Finds the PC on the network by itself, and can switch between two PCs
  • Firmware updates pushed over WiFi from the PC
  • USB keeps working as a fallback

End-of-night report

Windows notifications go quiet automatically while a match is live.
