VRG Füzet

One notebook for everything that comes up during the day. Notes, to-dos, measurements, materials, meter readings and walks all go into one store. Kits make it fit each part of the work or the house. It's forked from the VRG Sketcher's engine and ships in the APK; the phone below runs the same kits and the same rules in your browser.

Try it

  1. Tap ⚑ Nyitott. The 0.4 MΩ insulation reading breaks its 1 MΩ limit, the boiler service is overdue, and the ladder note offers to become a to-do.
  2. Open ⚒ Munka, then ◷ Munkaidő: hours add up per week. ▣ Anyagok counts "Dugalj" and "dugalj" as one material.
  3. Type kazan into the search without the accent. It finds the boiler entry in the Otthon kit.
  4. Write a note with ✎ Jegyzet, such as "elromlott a csap". Nyitott suggests moving it into Otthon as maintenance.
  5. In ⚙ Kitek, switch on the Kutya kit and a "no walk today" reminder appears. The export there is the same file format the phone writes.

Forked from the Sketcher

The Sketcher was already a note taker built from modules: fronts, a catalog that is pure data, and variants written by an agent. The fork keeps the engine's rules, drops the floor plan, and opens them to every kind of entry. The Sketcher itself is unchanged.

The four kits

How it grows

1 · Phone

⚙ Kitek → ✦ Kit kérése saves a request and opens the share sheet with a template.

2 · Claude

A session follows Mobile/notebook/PROTOCOL.md and writes one kit JSON.

3 · Check

The core tests parse every kit and refuse any error or warning.

4 · Back

Push, and the next APK carries it. Or load the file straight away under ⚙ Kitek.

A kit holds the four parts of the framework: entries (types and fields), views (log, list, tick-off list, totals), actions (quick chips) and rules (deadlines, limits, "not done in a while", keywords). A kit never holds code, so anyone can write one and the phone can always load it.
