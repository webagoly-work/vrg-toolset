§3Doboz-elrendezés 300 × 200 × 100

Felülnézet, levett fedéllel, mm-léptékben. A 230 V-os zóna L alakú: felül a DIN-sín, bal alul a kapcsolómodulok. A SELV elektronika a jobb alsó, válaszfallal leválasztott rekeszben ül. A falakon a csatlakozó családja jelzi a feszültséget, így nem lehet összecserélni: 230 V = IEC C13, DC = GX12, pixel = GX16-3, érzékelő = GX16-5.

készletből rendelni 230 V-os válaszfal / csatlakozó L N PE

A modulméretek ≈ értékek (hobbi-modulok tűrése ±5 mm) · a ház belső méreteit a beszerzett típus adatlapjáról kell visszaellenőrizni.

Fedél (kezelőoldal)

A–A metszet (magasság)

A fedélpanel csak a SELV rekesz fölé kerül, ahol az alkatrészek ≤ 25 mm magasak.

§11BRIDGE integráció

Elnevezés és szerep

  • Eszköz: bridge-fx-core-NN; entitás-előtag FX01 → light.fx01_d1, switch.fx01_k1, select.fx01_jelenet.
  • Termékcsalád: FX-CORE (központ), FX-SND (hang), FX-PAD (fali panel), FX-SENS (érzékelő). Mind ESPHome, mind a BRIDGE-DN Home Assistantjába jelentkezik.
  • Önálló működés: helyi web_server (internet és HA nélkül is tölt), SNTP idő, flash-ben a tanult kódok és programok. A VRG-szabály hardveres megfelelője: a doboz használhatja a BRIDGE-et, de nem igényli.

Kapcsolódási pontok

  • Shadow réteg: „SH” változatban 24 V= SELV betáp a shadow hálózatról (24→12 és 24→5 V DC/DC); a 230 V ilyenkor csak a K-csatornák terheléseihez kell.
  • P33: ROOM BOX-bővítményként beépíthető; FX-NET (W5500 / PoE) a BRIDGE_NET kábelre.
  • OmniComm: EnOcean (USB 300) és Zigbee (ZBDONGLE-E) kapcsolók HA-automatizmussal a select.fx01_jelenet-et hívják.
  • Zene: Music Assistant a BRIDGE-DN-en → FX-SND media_player. Spotify Premium fiókkal és a LIBRARY saját fájljaival; a CAP2 tartása play/pause.

script:
  # Jelenet kiválasztása (a select-en át → a felület is frissül)
  - id: scene_set
    mode: queued
    parameters:
      idx: int
    then:
      - lambda: |-
          if (idx < 0 || idx > 7) return;
          auto call = id(scene_sel).make_call();
          call.set_index(idx);
          call.perform();

  # A jelenet tényleges alkalmazása a kimenetekre
  - id: apply_scene
    mode: restart
    parameters:
      idx: int
    then:
      - lambda: |-
          if (idx < 0 || idx > 7) return;
          id(scene_idx) = idx;
          if (idx > 0) id(last_scene) = idx;
          if (idx != 6) id(night_active) = false;
          if (idx == 7) return;  // Egyedi: kézi beállítás marad

          float m = id(master_dim).state / 100.0f;
          if (std::isnan(m) || m <= 0.0f) m = 1.0f;

          auto mono = [m](light::LightState *l, float br, const char *fx) {
            if (br <= 0.0f) { auto c = l->turn_off(); c.perform(); return; }
            auto c = l->turn_on();
            c.set_brightness(br * m);
            c.set_effect(fx);
            c.perform();
          };
          auto pix = [m](light::LightState *l, float br, float r, float g, float b, const char *fx) {
            if (br <= 0.0f) { auto c = l->turn_off(); c.perform(); return; }
            auto c = l->turn_on();
            c.set_brightness(br * m);
            c.set_rgb(r, g, b);
            c.set_effect(fx);
            c.perform();
          };
          auto sw = [](switch_::Switch *s, bool on) { if (on) s->turn_on(); else s->turn_off(); };
          auto acs = [&](bool a, bool b, bool c, bool d) { sw(id(k1), a); sw(id(k2), b); sw(id(k3), c); sw(id(k4), d); };
          auto rls = [&](bool a, bool b, bool c, bool d) { sw(id(k5), a); sw(id(k6), b); sw(id(k7), c); sw(id(k8), d); };

          switch (idx) {
            case 0:  // Ki
              acs(false, false, false, false); rls(false, false, false, false);
              mono(id(d1), 0, "None"); mono(id(d2), 0, "None"); mono(id(d3), 0, "None"); mono(id(d4), 0, "None");
              pix(id(p1), 0, 0, 0, 0, "None"); pix(id(p2), 0, 0, 0, 0, "None");
              break;
            case 1:  // Ambient
              acs(true, false, false, false); rls(false, false, false, false);
              mono(id(d1), 0.45f, "Lassú hullám"); mono(id(d2), 0.30f, "None");
              mono(id(d3), 0, "None"); mono(id(d4), 0, "None");
              pix(id(p1), 0.35f, 1.0f, 0.60f, 0.25f, "None");
              pix(id(p2), 0.25f, 1.0f, 0.55f, 0.20f, "Lélegzés");
              break;
            case 2:  // Mozi
              acs(false, false, false, false); rls(false, false, false, false);
              mono(id(d1), 0.08f, "None"); mono(id(d2), 0, "None"); mono(id(d3), 0, "None"); mono(id(d4), 0, "None");
              pix(id(p1), 0.12f, 0.10f, 0.20f, 1.0f, "Lélegzés");
              pix(id(p2), 0, 0, 0, 0, "None");
              break;
            case 3:  // Party
              acs(true, true, false, false); rls(true, false, false, false);
              mono(id(d1), 0.9f, "Lélegzés"); mono(id(d2), 0.9f, "Stroboszkóp");
              mono(id(d3), 0.8f, "Lélegzés"); mono(id(d4), 0.8f, "Stroboszkóp");
              pix(id(p1), 1.0f, 1.0f, 0.0f, 0.6f, "Tűzijáték");
              pix(id(p2), 0.8f, 1.0f, 1.0f, 1.0f, "Szivárvány");
              break;
            case 4:  // Gyertya
              acs(false, false, false, false); rls(false, false, false, false);
              mono(id(d1), 0.5f, "Gyertya"); mono(id(d2), 0.5f, "Gyertya");
              mono(id(d3), 0.4f, "Gyertya"); mono(id(d4), 0.4f, "Gyertya");
              pix(id(p1), 0.5f, 1.0f, 0.45f, 0.08f, "Tűz-vibrálás");
              pix(id(p2), 0.4f, 1.0f, 0.40f, 0.05f, "Tűz-vibrálás");
              break;
            case 5:  // Vihar
              acs(false, false, false, false); rls(false, false, false, false);
              mono(id(d1), 0.9f, "Villám"); mono(id(d2), 0, "None"); mono(id(d3), 0, "None"); mono(id(d4), 0, "None");

§14Élesztési sorrend

Hardver és szoftver felváltva. Ha egy lépés piros, ott kell megállni: minden hiba annál a lépésnél a legolcsóbb, amelyik behozta.

  1. HWTápegységek próbapadon: terhelés nélkül, majd terhelve (KWS-065C). 5,0 V és 12,0 V a kimeneten.
  2. SWS3 flashelése USB-n (UART C-port): ESPHome alap, WiFi, helyi web_server elérhető telefonról.
  3. HW/SWI²C: OLED (0x3C) + BH1750 (0x23) 3,3 V-on; PCF8575 5 V-on a szintillesztő mögött → a scan 0x20-at is mutat.
  4. HW/SWRelé- és SSR-modulok terhelés nélkül: LED-ek követik a K1–K8 kapcsolókat; ESP reset alatt is KI maradnak.
  5. HW/SWFX-DC4: előbb a PWM generátorral MCU nélkül bemérni, utána D1–D4 effektekkel 12 V-os LED-szalagon.
  6. HW/SWFX-PIX2: rövid WS2812B szakasz P1-en, effektek; P2 WS2815-tel.
  7. SW433 MHz: tanítás telefonról (KIN-1/2, TAV-A…D), majd IR. Ellenőrzés az „Utolsó RF-IR kód” entitással.
  8. SWCAP1/CAP2 multi-click, PIR + lux éjszakai automata, A/B időprogram egy perccel előre állítva.
  9. HW230 V oldal feszültségmentesen: szigetelésmérés, PE-folytonosság, csak utána K1–K4 izzóterheléssel, F1–F5 biztosítókkal.
  10. HWDobozolás: válaszfal, G1/G2 átvezetők, J1 fedélpanel. Hőpróba 1 órán át teljes terheléssel (W3230 + V1).

§15Biztonsági jegyzetek

Előtét áramkör: 30 mA-es RCD és B10/B16 kismegszakító a lakás elosztójában (MSZ HD 60364-4-41). A dobozban lévő Q1 a belső huzalozást és a tápegységeket védi.
  • Zónák: a 230 V és a SELV között válaszfal. Csak G1 (DC táp) és G2 (jel-szalagkábel) megy át, mindkettő 230 V-os szigetelésű vezetékkel.
  • SELV marad SELV: a két tápegység 0 V-ja egy csillagpontban közös, de nem kerül PE-re (különben PELV lenne).
  • PE: DIN-sín, fém alkatrészek és a C13 aljzatok PE ága az X1 PE sorkapcsokra.
  • SSR: csak AC-t kapcsol, és jellemzően zárlatosra hibásodik, ezért van csatornánként T2A biztosító. Kikapcsolt állapotban kis szivárgó áram folyik, amitől egy LED-fényforrás halványan derenghet; ilyenkor K5–K8 mechanikus relé vagy söntkondenzátor a megoldás.
  • Olcsó relémodul: a tekercs és az érintkező közti távolság nem garantál megerősített szigetelést. Ügyfélnél tartós beépítéshez a PRO szint interfészreléje kell.
  • Hő: 4 SSR 1 A-en ≈ 6 W, a tápok vesztesége ≈ 10 W. Zárt dobozban a W3230 45 °C felett indítja a ventilátort.
  • 5/12 V választás: rossz feszültség tönkreteszi az 5 V-os szalagot. Az átkötés az X3-on van, a külső aljzatot színgyűrű jelöli (piros = 12 V, kék = 5 V).
  • Pixel: 330 Ω soros ellenállás az első LED előtt, 1000 µF a betápon. A GX csatlakozót csak feszültségmentesen szabad dugni.
