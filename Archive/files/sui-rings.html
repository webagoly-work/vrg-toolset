Primitive API

    

      
ticks(g, {cx,cy,r,n,len,every,majorLen})
Tick ring. Every every-th tick is a longer major tick.

      
sector(cx,cy,r0,r1,a0,a1)
Annular wedge path. Used for menu segments and arc gauges.

      
callout(g, {x,y,r,dx,dy,title,sub,actions})
Lock circle, leader line that draws itself, then the label fades in.

      
reticle(g, {cx,cy,r,gap})
Faint centering lines on a separate layer that never pans.

      
branchTree(svg, main, branches)
main as the spine, each worktree forking below it with ahead/behind and dirty state. Clicking a commit traces its path.

      
radar(svg, {axes,values,base,max})
Attribute matrix with a 10-level grid, glow outline and a dashed ghost of the starting build.

      
vitals strip + overlay shell
Left menu picks the section, tabs pick the shell or log, right panel holds options. Corner brackets mark it as a floating overlay.
