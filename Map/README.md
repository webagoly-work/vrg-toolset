# VRG Térkép

Offline, keyless map of Hungary in our own **VRG Terep** style (high-contrast field/day look):
address search, 3D buildings, terrain and hillshade. START key **M**, server **H** on
`http://localhost:8802/`. Research and the later phases (Budapest building heights, own 3D viewer,
field layers): `docs/research/reports/VRG Map - detailed maps, 3D city and field layers.md`.

## First run

```bash
node Map/tools/fetch-data.js
```

Downloads ~1.7 GB into `Map/data/` (gitignored), all free and keyless; START does this by itself the
first time **M** is picked. `--refresh` fetches a newer OSM week, `--only=basemap,terrain,…` one part.

| Part | File | Source | Licence |
|---|---|---|---|
| basemap | `hungary.pmtiles` (~1 GB, z0-15) | newest Protomaps daily planet build, Hungary box | ODbL © OpenStreetMap |
| terrain | `terrain.pmtiles` (~0.35 GB, z0-12) | Mapterhorn planet (Copernicus GLO-30 …) | per mapterhorn.com/attribution |
| osm | `src/hungary-latest.osm.pbf` (~0.33 GB) | Geofabrik | ODbL |
| addresses | `addresses.json` | built from the .pbf by `tools/build-addresses.js` | ODbL |
| fonts, sprites | `fonts/`, `sprites/` | protomaps/basemaps-assets | OFL / see repo |

`Map/data/manifest.json` records source, date, licence and size of every part. The pmtiles CLI goes
to `H:\VRG\Full\tools\pmtiles`.

## Files

- `vrg-terkep.html` — the page (MapLibre GL JS + PMTiles from `Vendor/`, see `vendor-manifest.json`).
- `serve.js` — static server with HTTP Range (a `.pmtiles` file is read in pieces, no tile server).
  `--allow-remote` adds a test-only proxy so `?remote=1` can run without the download.
- `style/terep.json` — generated by `tools/build-style.js`; edit the script, not the JSON.
- `tools/build-addresses.js` — dependency-free OSM .pbf reader: every settlement in Hungary, every
  street and house number in the Budapest + Pest county box.

## Using it

- Search: `Váci u. 12`, `1062 Andrássy út 60`, `Budapest V. ker. Váci utca 14`, `Budaörs Fő utca`.
  Accents and abbreviations (u., krt., sgt., rkp., ltp.) are optional. Offline first; the
  "Keresés az interneten" row asks OSM Nominatim (online, one request a second).
- Picking a result flies there tilted and turned, so terrain and building heights read at once.
- Keys: `/` search · `3` 3D buildings · `T` terrain · `N` north · `G` Google view · `Esc` close.
- URL: `#zoom/lat/lon/bearing/pitch` is the camera; `?q=…` searches on load; `?embed=1` is the slim
  UI for embedding in Kapu or the Planner.

## Google view (optional, online)

`G` opens a panel beside the map, aimed at the same place, heading and tilt:

- **No key:** Google's keyless satellite embed (2D) plus links to Google Earth / Google Maps that open
  with the same angle.
- **With a Map Tiles API key** (pasted in the panel, kept in this browser's localStorage): Google's
  photorealistic 3D city in CesiumJS (loaded from jsDelivr only then). The free quota is 1 000 root
  requests a month; each opening uses one, and the panel counts them. Google's terms forbid caching
  or extracting this data: it is a view, never part of our map.
