Layers

Active layer gets new items. 👁 = layer on/off · P/D/C/W/B = path·device·cable·wall·build sub-layers.

Active level (new items)

Path (pálya – elsődleges)

Magasság-kijelző
Draw the empty pathway first (same snapping/heights as cable). ↑/↓ = rajz magasság · Ctrl = fal másik oldala · Enter = kész.

Cable (másodlagos)

Rajz magasság
Ctrl = wall's other side (sticky) · ↑/↓ = height line · ←/→ = rotate · Space = kötődoboz · Enter = finish · Esc = cancel.

Device

Falra téve a Ctrl a fal két oldala közt vált (mint a pályánál). ↑/↓ magasság, ←/→ típus. Elosztószekrény: jobb klikk a falon → „Elosztószekrény ide".

Routing

Recompute re-runs every device (Szükséges erek) to its board. Clear removes routed wires (keeps manual section circuits).

Áramkörök

A rajzon lévő áramkörök — láthatóság, kiemelés, szerkesztés.

Dokumentáció

Számozás → D1, K1, L1, EL1… + circuit sorszám. Lists come from the routed circuits (Copy / CSV).

Objects

Kiválasztás → kattints a rajzra. Kijelölve: WASD mozgat · Q/E forgat · ↑/↓ emel · jobb klikk → méret.

Build (snaps to wall)

Click a wall to place. Right-click an object → Rotate / Delete.
